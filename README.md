# 数学建模 C 题题面、正式论文与配套技能

本仓库整理了全国大学生数学建模竞赛 C 题的完整题面与附件、正式论文源文件、完整支撑材料，以及一套面向 C 题全流程工作的配套技能。内容适合用于审题训练、建模方案设计、论文写作、科研绘图、提交冻结和最终审核。

## C 题题目

`C题题目/` 保存完整原始材料：

- `C题.pdf`：赛题正文；
- `附件1.xlsx`—`附件4.xlsx`：题目提供的数据附件；
- `附件5/`：问题一至问题四对应的结果填写模板。

仓库仅整理原始题面与附件，不在该目录中混入论文、求解结果或过程缓存。

## 支撑材料

`支撑材料/` 保存论文结果复核与复现所需的未压缩材料，包括完整计算结果、源程序、补充结果与图表、人工智能工具使用详情及文件校验清单。仓库未重复收录支撑材料压缩包。

## 审题档案

`审题档案/` 公开从题意理解到验收核对的关键决策依据：

- `赛题解读_final.md`：赛题结构、目标与约束的完整解读；
- `歧义与口径确认.md`、`题意决定冻结合同.md`：关键歧义的处理及建模口径；
- `附件审计.json`：原始附件的结构与质量审计结果；
- `验收报告.md`：求解结果的验收记录；
- `扩展核验/最终外部交叉复核_第三份网上数据.md`：不作为主模型输入的外部交叉核验说明。

## 配套技能

| 技能名称 | 主要用途 |
|---|---|
| `数模审题` | 对单道 C 题完成证据化审题、口径冻结、模型选择、编程求解与结果验证 |
| `数模论文写作` | 在题意、模型和结果冻结后完成论文正文、公式、摘要、结论与图表叙事 |
| `数模论文审核` | 对论文、代码、结果、图表和支撑材料执行提交前审计 |
| `cumcm-c-paper-figure` | 按“论点—证据—图表类型”的逻辑生成 C 题科研图表方案 |
| `cumcm-paper-freeze` | 将最终论文、代码、结果和支撑材料组装为冻结提交目录 |
| `unflatten-ppt` | 将既定流程图或栅格参考重建为可编辑演示文稿 |

每个技能在 `skills/<名称>/` 下保留完整源码。

### 安装方法

将需要的技能目录复制到：

```text
%USERPROFILE%\.codex\skills\
```

重新启动或刷新代码助手后，即可在技能列表中使用。

## 模型与实验

`模型与实验/` 汇总四问的模型选择、求解代码与消融对照实验：

- `模型与结果/`：四问模型方案与结果说明、口径冻结、建模粒度合同、约束冻结表、模型假设台账、论文补充实验总账；
- `求解代码/`：`common_data.py`、`dispatch_core.py` 与 `q1_solve.py`—`q4_solve.py` 四问正式求解程序；
- `消融与对照实验/`：Q3 信息模块 2³ 消融与更新时间组合、Q2 风险分位数敏感性、Q1 单目标与词典序 LP 对照、未来信息扰动无前视核验、LP-MILP 交叉核验、α 标定与五点敏感性、Q3/Q4 精修对照，均含 `results/` 与独立复算 `validation/`。

详细索引见 `模型与实验/README.md`。其中逐时段完整明细 CSV 体积过大未纳入仓库，可由仓库内脚本原样重新生成。
