# 数学建模论文模板

本仓库提供一份面向全国大学生数学建模竞赛 C 题写作的 LaTeX 论文骨架，参照 2024 年 C 题论文模板的标题层级和基础排版设置整理。

## 文件说明

- `2026数模论文骨架.tex`：论文主文件，包含摘要、问题重述、问题分析、模型假设、符号说明、数据预处理、三个问题的建模与求解、模型评价与结论、AI 工具使用声明、参考文献和附录的标题骨架。

模板保留一级、二级和三级标题，不包含具体赛题正文、数据、模型结果或图表。

## 编译环境

- 建议使用 XeLaTeX 编译；
- 中文字体为 SimSun，英文字体为 Times New Roman；
- 需要常见的 `ctex`、`titlesec`、`geometry`、`amsmath`、`booktabs`、`longtable`、`graphicx`、`caption` 和 `hyperref` 宏包。

## 使用方法

在终端中进入文件所在目录，运行：

```bash
xelatex 2026数模论文骨架.tex
```

随后按照当届赛题实际小问数、任务链和官方格式要求，删改不适用的小节并补充正文。提交前请核对当届竞赛的格式、页数、AI 使用声明和材料提交要求。
