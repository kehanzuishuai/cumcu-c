# Claim → Evidence → Chart Type

只在选图或审查“这张图是否选对”时读取本文件。

## 1. 三步记录

生成每张正文图前，先在内部记录：

```text
Claim: 这张图要支持的一个结论
Evidence: 支撑结论的数据对象与结构
Chart Type: 为什么该图形编码最适合该证据
```

如果 Evidence 只有汇总统计量，就不能宣称展示样本分布；如果横轴是时间或连续参数，就不能因为实现方便改画柱状图。

图型选定后继续读取 [visual-information-density.md](visual-information-density.md)。图型正确但点数、区间分辨率或有效信息单元不足时，仍不能进入正式渲染。

信息密度通过后继续读取 [evidence-richness-portfolio.md](evidence-richness-portfolio.md)。同一 Claim 确有互补证据时可组成分层或分面科研图；证据独立、冗余或对象不同则保持分开。组合不是默认目标。

每张图选出基础图后都调用轻量 `advanced_figure_candidate_gate()`；无结构候选或无实质信息增益时保留当前 line、bar、dot、interval 等。只有返回候选或边界不明确时才读取 [advanced-figure-candidates.md](advanced-figure-candidates.md)。

## 2. 证据—图型矩阵

| Claim | 必需 Evidence | 正文首选 | 常见误用 |
|---|---|---|---|
| 随时间变化、预测是否跟随波动 | 有序时间序列 | 折线 + 分界 + 区间 | 每期一根柱 |
| 连续参数变化是否稳定 | 连续参数扫描 | 灵敏度曲线；双参数用热力图 | 只画 ±10% 三根柱 |
| 样本形态、偏态、多峰或尾部 | 原始/模拟/重采样样本 | 直方图 + KDE、ECDF | 三个汇总值冒充分布 |
| 两变量关系或非线性趋势 | 成对观测 | 散点 + LOESS/拟合 + CI | 把 x 分箱后画柱 |
| 多变量相关结构 | 相关/距离矩阵 | 热力图，必要时聚类 | 多组并排柱 |
| 离散类别均值/总量比较 | 类别 + 数值，必要时重复观测 | 水平/竖直柱或点图 + 误差 | 类别过多仍画竖柱 |
| 排名与得分 | 对象 + 得分/排名 | 水平条形或棒棒糖 | 雷达图承担精确排名 |
| 估计量及区间 | 点估计 + CI/分位区间 | 森林图/点区间图 | 柱 + 粗误差棒 |
| 风险—收益折中 | 多方案的收益与风险 | Pareto 散点 | 两组柱分别画风险和收益 |
| 多期多对象决策 | 对象 × 时间 × 决策量 | 看轨迹用折线/小多图；看单元格模式用热力/矩阵 | 不区分 Claim 就统一改热力图 |
| 地理点位、区域差异或空间流动 | 经纬度点、有效区域几何 + 连接键，或真实起终点/路径 | 点位图、区域着色图、比例符号图或路线/流向地图 | 只有距离矩阵也套底图；用原始总量解释相对强度 |
| 生产、机器或任务排程 | 任务/工序 + 资源 + start/end/duration + 约束检查 | 以资源为行的 Gantt / scheduling timeline | 把对象 × 时间热力矩阵或普通横条称作 Gantt |
| 组成关系 | 部分之和等于整体 | 100% 堆叠条或面积图 | 独立指标强行堆叠 |
| 分类性能 | 混淆计数、概率或阈值扫描 | 混淆矩阵、PR/ROC、阈值曲线 | 只画 Accuracy 柱 |
| 改进是否有效 | 同口径 baseline 与 improved | 同尺度并排面板/差值图 | 只展示最终模型 |

## 3. 柱状图门禁

只有以下问题全部回答“是”，才允许使用柱状图：

1. 横轴是离散类别，而非时间、距离、权重、阈值或其他连续变量？
2. 结论是比较类别大小，而非解释分布、相关、区间或变化轨迹？
3. 类别数量和标签长度适合正文；约 6 类以上是否已比较过水平条、点图、热力图或分面？
4. 柱长从 0 起不会掩盖核心差异？若会，是否应改用点图/森林图？
5. 多系列是否仍能留出清晰组间空白？

通过后仍执行：单柱宽 `0.45–0.60`，默认 `0.52`；分组总宽不超过类别间距的 `0.72`；无纯黑粗边；少量关键值才直接标注。

## 4. 下尾风险判定

### 有样本

可画“样本利润下尾分布”：直方图/ECDF + KDE（可选）+ 均值线 + `VaR_α` + `x≤VaR_α` 尾部着色 + `CVaR_α` 数值。

### 只有指标

只有均值、标准差、5% 分位数、CVaR 或置信区间时：

- 使用森林图/点区间图；
- 标题写“风险指标比较”“收益区间比较”；
- 不写“概率密度”“经验分布”或“尾部分布”。

### 多方案

样本足够时，优先 ECDF、小多图或箱线；方案较多时不要重叠多张直方图。

## 5. Map 选择门禁

只有以下条件成立才选 Map：地理坐标、区域边界或空间路径本身是 Claim 的证据；若地理位置不影响结论，优先用 network、matrix、bar/dot 或表格。

- 点事件/设施位置：每点有可核验经纬度，用 point map；数值大小确有意义时才用 proportional-symbol map。
- 区域率、密度、比例或分级：有合法边界及唯一连接键，用 choropleth；主张相对强度时不得直接用人口、销量等原始总量着色。
- 区域总量比较：优先比例符号或地图 + 精确排序图；若仍用区域着色，必须在图题和正文明确“总量”，不得解释为发生率或密度。
- 路径/流动：必须有真实起点—终点、方向及路径/流量，才用 route/flow map；只有邻接关系或边权时属于 network，不因节点有地名就自动套底图。

绘制前最低检查：坐标参考系（CRS）与经纬度顺序、边界来源和版本、区域 ID 唯一性及未匹配率、聚合层级、单位与缺失值。任一关键字段不清先返回补数据，不靠在线工具自动匹配猜测。

## 6. Scheduling/Gantt 选择门禁

真正的排程 Gantt 必须同时存在任务/工序标识、机器/资源、`start`、`end` 或 `duration`；矩形长度必须等于真实占用时长。编码固定为“x=时间、y=机器/资源、条段=任务占用区间”，颜色只承担作业/订单或必要状态。

发布前必须由求解结果回查：`end-start=duration`、同一资源不重叠、作业内 precedence、释放时间/交期/维护窗口等题设约束，以及图示 makespan 与结果表一致。比较 baseline/improved 时使用同时间尺度的对齐面板，不把两套区间重叠在一张图上。

Gantt 不等于对象 × 时间值矩阵、算法收敛曲线、一般水平条、Sankey/alluvial 或流程图。缺少任务时段时使用 heatmap/table；只有工序依赖而无已求得时刻时用网络/precedence 图，不能伪造 Gantt。

## 7. 最小证据原则

- 一张图只承担一个主 Claim；次要信息必须能帮助验证，不是装饰。
- 图型升级不等于复杂化：能用一条曲线说清，就不要做四面板。
- 多个互补证据可共同支撑一个主 Claim，但每层都必须有独立的核验职责；无职责的 KDE、阈值、阴影或面板应删除。
- 图表数量由证据链决定，不由“每问至少几张”决定。
- 全文图型组合只用于发现机械套图；重复证据结构允许重复图型，不设置图型多样性配额。
- 决策顺序固定为“证据匹配 > 信息表达 > 可读性 > 全文多样性 > 高级感”；heatmap 不享有替代基础图的默认优先级。
- 少量汇总值即使可以画成点，也不等于值得单独成图；先比较三线表与正文数字的信息效率。
