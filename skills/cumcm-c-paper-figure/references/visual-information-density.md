# Visual Information Density Gate

只在图型已选定、准备写正式绘图代码，或成图出现“空、弱、看不清”时读取本文件。

## 1. 目的与边界

本门禁判断的不是配色和美观，而是：现有数据能否在当前图型和坐标尺度下形成**可辨识、可解释、可核验**的视觉证据。

门禁不得改变模型事实：

- 新采样点必须重新运行模型、优化器、Bootstrap 或 Monte Carlo；
- 禁止复制点、插值、平滑或随机抖动后冒充新增结果；
- 坐标缩放只能提高区间可见度，不能裁掉反例或制造差异；
- 证据不足时允许换表或删除图，不要求每个结果都“图形化”。

## 2. 四种输出

| 状态 | 含义 | 后续动作 |
|---|---|---|
| `RESAMPLE` | 连续曲线/尾部估计的真实点数不足 | 回到模型或模拟增加真实计算点，再复检 |
| `RESCALE` | 数据或区间相对坐标跨度太小 | 使用建议范围、局部放大或总览 + 放大，再复检 |
| `RECHART` | 当前证据对象不能支撑所选图型 | 换成 ECDF、森林图、三线表或正文数字 |
| `PASS` | 信息密度和可见度足够 | 进入语义配色与渲染阶段 |

当多个问题同时存在，优先级为 `RECHART > RESAMPLE > RESCALE > PASS`，但仍要执行返回的全部建议。

## 3. 默认诊断量

这些阈值是审查触发线，不是统计定理；离散可行集合、昂贵求解或领域规范可合理调整，但必须说明原因。

| 指标 | 计算 | 默认触发 |
|---|---|---|
| 连续横轴有效点数 | `N_unique = unique(x)` | `<5` 必须 `RESAMPLE` 或改为离散情景比较；`5–8` 通常补到 9–21 |
| 最大采样空档 | `max(diff(sort(x))) / range(x)` | `>0.35` 时检查是否漏掉拐点/策略切换 |
| 分布样本数 | 有限样本 `n` | `<30` 不画 KDE；`30–199` 优先 ECDF并谨慎平滑；常规直方图+KDE建议 `≥200` |
| CVaR 尾部样本数 | `n_tail = count(x≤VaR_α)` | `<20` 时优先增加模拟/重采样或报告不确定性 |
| 区间可见比 | `median(U-L) / axis_span` | `<0.05` 返回 `RESCALE` |
| 数据占轴比 | `data_envelope_span / axis_span` | `<0.25` 检查是否被远端 0 线/基准拉空 |
| 边界距离 | 点到上下左右边界的最小归一化距离 | `<0.06` 时标注向图内偏移或增加留白 |
| 汇总信息单元 | 无区间/关系/分布的独立汇总值数量 | 仅 3–5 个时优先表格或正文；若声称“分布”直接 `RECHART` |

## 4. 三类实测纠正

### fig6 型：风险权重只有 0、0.2、0.4

- `N_unique=3`，连续曲线返回 `RESAMPLE`；
- 默认建议求解位置为 `0, 0.05, …, 0.40` 共 9 点；若在某区间发生策略切换，再局部加密；
- 新 y 值必须重新运行优化/仿真，不能连接或插值原三点冒充；
- “最终选择”只标一个点；右端/下端数值使用 `annotate_point_safely()` 向图内偏移。

若计算成本不允许增加点，图名和正文降级为“三种风险权重情景比较”，可用点图或小表，不画连续前沿。

### fig7 型：五个利润汇总指标

- 均值、5% 分位、CVaR、1% 分位和最小值只是不同统计量，不构成样本分布；
- 若能取得 Monte Carlo/Bootstrap 利润样本：改画真实直方图/ECDF + KDE + 均值 + VaR/CVaR 尾部；
- 若无样本：改名为“利润风险指标比较”，使用森林图/点区间或三线表；只有五个无区间数值时表格通常比棒棒糖图更强。

### fig10 型：CI 在 0–40 横轴上退化为点

示例 CI 为 `[36.35,36.73]`、`[34.99,36.69]`、`[34.43,36.11]`。若横轴约为 `-1.5…42`：

- 中位区间宽度/轴跨度约为 4%，返回 `RESCALE`；
- 建议聚焦到全部 CI 包络并留 12%–18% 边距，约为 `34.1…37.1`；
- 零效应值 0 位于图外时，在图中或图注说明“0 位于显示范围左侧，全部 CI > 0”；
- 若必须直观看到与 0 的距离，采用“总览 + 局部放大”而不是牺牲区间分辨率。

## 5. 代码接口

```python
from cumcm_figure_style import (
    visual_information_density_gate,
    suggest_sampling_grid,
    suggest_interval_xlim,
    focus_interval_axis,
    annotate_point_safely,
)
```

- `visual_information_density_gate(...)`：返回状态、问题码、建议和诊断量；
- `suggest_sampling_grid(...)`：只生成待求解的 x 位置，不生成 y；
- `suggest_interval_xlim(...)`：从 CI 包络计算聚焦范围；
- `focus_interval_axis(...)`：应用聚焦范围，并可说明零基准位于图外；
- `annotate_point_safely(...)`：根据点在坐标中的相对位置，将文字向图内偏移。

完成动作后必须重新运行门禁；不能把 `RESAMPLE/RESCALE/RECHART` 当作普通警告忽略。
