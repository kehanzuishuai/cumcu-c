# A4 视觉审计

只在成图已生成、准备交付或插入论文时读取本文件。

## 必须执行的闭环

```text
Render → Open → Visual Audit → Revise
```

1. 同时输出 PDF 与 400 dpi PNG。
2. 在渲染前确认 Visual Information Density Gate 已为 `PASS`。
3. 确认 Evidence Richness Gate 已处理；复合图只保留同一 Claim 的互补层，全文 Figure Portfolio Gate 无未复核的 `REVIEW`。
4. 用 `scripts/render_a4_preview.py` 将 PNG 以最终宽度放入 A4 白页。
5. 实际打开预览，不以“脚本无报错”替代。
6. 发现问题后修改源码、重新运行密度与证据丰富度门禁并重新渲染；审计对象必须是最新输出。

## 审计顺序

### 1. 先看整体

- 3 秒内能否说出主结论？
- 图型是否匹配证据，而不是“又一张柱状图”？
- 复合图是否仍只有一个主 Claim，各层是否互补而非拼盘？
- 全文连续同型图是否来自重复证据结构，而不是模板惯性？
- 版面是挤、散、重还是失衡？
- 子图是否真的需要同时存在？

### 2. 再看几何

- 柱宽是否约 0.45–0.60，分组之间是否有明显留白？
- 轴线、误差棒、marker、边框是否抢过数据？
- 图例是否遮挡峰值、异常点、区间或尾部？
- 面板间距是否一致；共享轴是否重复标签？
- 连续曲线是否因点数太少而只剩几段直线？
- CI/误差线是否因横轴跨度过宽而看起来像点？
- 边界标注是否碰到刻度、轴标题或裁切边界？
- Marimekko、100% stacked bar 等满幅组成图是否在理论 100% 边界外出现 autoscale/margin 白带？

### 2.1 满幅组成图边界门禁

- 纵向 100% stacked bar：比例轴精确为 `[0, 1]` 或 `[0, 100]`，y-margin 必须为 0；横向版本对应检查 x 轴。
- Marimekko：比例轴满足上一条；总量轴同时精确贴合真实累计边界，两个方向的 margin 均为 0。
- 不得为容纳 `100%`、总量或类别标签把比例上限改成 `105%`，也不得在总量轴前后加无数据留白。
- 顶部/底部标签用 `annotate(..., textcoords='offset points')` 向图内偏移；标签过密则只标关键对象或放图例，不扩大数据坐标。
- 绘制全部 patch 后调用 `lock_full_span_composition_axis()`；随后用 `audit_full_span_composition_axis()` 或已集成该标签的 `audit_figure()` 复核。任何后续 autoscale 都必须再次审计。

### 2.2 Map 专项门禁

- 坐标参考系（CRS）、经纬度顺序与投影已记录；点位落在合理范围，不出现整体平移、镜像或落海等坐标错误。
- 区域边界来源、版本、行政层级及连接键可追踪；重复 ID、未匹配区域和缺失值已检查，不把无数据误画成 0。
- choropleth 若表达率、密度或比例，分母、单位和时间窗口明确；原始总量不被解读为空间强度。
- 比较地图共享投影、地理范围、分级断点与色标；比例符号的面积而非半径对应数值。
- 路线/流向图只有真实路径或起终点流，方向与线宽语义明确；若地理位置不影响 Claim，应退回 network/matrix。
- 静态 A4 图不依赖 hover 才能读懂；底图、边界和地名不压过数据，也不泄露敏感位置或身份信息。

### 2.3 Scheduling/Gantt 专项门禁

- 每个条段有可追踪的 job/order、task/operation、machine/resource、start、end/duration，且条长与真实 duration 一致。
- 同一资源条段无非法重叠；作业内 precedence、release time、due date、setup/maintenance 等已建约束与图示一致。
- 图示最晚完工时刻与结果表 makespan 一致；求解状态为 `FEASIBLE` 时不得在图题写“最优”。
- 资源行、时间单位与颜色语义清楚；idle 为空白，只有模型显式定义时才编码 setup、downtime 或 waiting。
- baseline/improved 面板使用同一时间尺度、资源顺序和颜色映射；任务过多时分面/附录，不缩字或给每段随机颜色。

### 3. 再看语义

- 主方案、对照、改进、风险、基准是否与全文同色？
- 红色是否只表达风险/异常？
- 线型、hatch 和 marker 在灰度下是否仍可区分？
- 标注是否只指向关键阈值、极值、膝点或异常？

### 4. 最后看排版

- 最终尺寸下最小有效文字是否仍约 ≥7.5 pt？
- 中文、负号、公式、上下标、百分号是否正常？
- 坐标轴是否有变量含义和单位？
- PDF/PNG 是否裁字、留白过多或比例失真？
- 图内标题是否与论文图题重复？

## 阻断条件

出现以下任一项，不得标记 `FINAL`：

- 未打开最终渲染结果；
- 图型与证据不匹配；
- Visual Information Density Gate 未通过；
- 复合图混入多个无共同对象的主 Claim，或存在无证据职责的装饰层；
- Figure Portfolio Gate 的 `REVIEW` 尚未完成选型复核；
- “分布图”没有样本分布证据；
- 连续参数曲线点数不足且新增点不是重新求解所得；
- 区间在最终坐标跨度下不可辨；
- 文字在最终宽度下不可读；
- 图例或标注遮挡关键数据；
- 语义颜色在同篇论文中漂移；
- 裁字、缺字、乱码或输出文件损坏；
- 柱子明显粗重、类别过密却未重构。
- 满幅组成图的比例轴未锁定理论 100% 边界、仍有默认上/下留白，或 Marimekko 总量轴超出真实累计边界；
- 为放置满幅组成图标签而扩大坐标范围。
- Map 的 CRS、边界/连接键或统计口径缺失，区域未匹配，或比较地图使用不可比色标；
- Scheduling/Gantt 缺少真实任务时段，或工期恒等式、资源互斥、precedence、release/due、makespan 与最终结果不一致。

## 常见错误与确定性纠正

### 1. 颜色太多

保留 3–5 种核心语义色；其余对象灰化、拆面板或只高亮关键对象。

### 2. 图例挡曲线

移到空白角、图外右侧；只有少量曲线时可直接标线尾。

### 3. 轴名程序化

将 `value`、`index`、`data`、`score1` 改成题目语义与单位。

### 4. 图太小

减少面板、增大整体尺寸或把次要图放附录，不继续缩字。

### 5. 双 Y 轴

优先改为上下两个共享 x 的对齐面板。

### 6. 柱轴截断

恢复 0 起点；研究微小差异时改为 dot/forest/line，不截断柱轴。

### 7. 网格过重

只保留 major grid，降低 alpha 与线宽。

### 8. 图内标题重复图题

删除图内标题，保留论文图题；子图仅留短标签。

### 9. 折线类别过多

比较 small multiples、Top-N + 其余灰化、分组均值 + CI；只有对象 × 时间/指标确为二维矩阵时才比较 heatmap。

### 10. 灵敏度只有 ±10% 三点

连续参数改为 9–21 个真实求解点并标基准；禁止用插值伪造新结果。

### 11. 每问都用柱状图

重跑 `Claim → Evidence → Chart Type`：趋势用 line，样本形态用 distribution/ECDF，关系用 scatter/matrix，连续参数用 curve，风险—收益用 Pareto，区间用 forest。bar 只保留离散大小比较。

### 12. 汇总风险指标被称为分布

有样本时补 histogram/ECDF、允许时 KDE、均值、VaR 和 CVaR 尾部；无样本时改名“风险指标比较”，使用 forest/point-interval/table。

### 13. 每张图使用不同颜色和边框

先建立全文语义映射，再调用统一 publication layer；禁止退回 Matplotlib/Office 默认循环色和纯黑粗描边。

### 14. 连续曲线只有 3 个点

返回 `RESAMPLE`，建议 9–21 个重新计算位置，在拐点/策略切换处加密；y 必须重新运行模型。

### 15. CI 视觉退化为点

计算 `median(CI width)/axis span`。低于约 5% 时返回 `RESCALE`，聚焦 CI 包络并留边；0 若在图外必须说明，必要时使用总览 + 放大。

### 16. 边界标注与轴/刻度重叠

调用 `annotate_point_safely()` 向图内偏移；必要时只增加 3%–6% 数据留白并只标关键点。

### 17. 为避免重复而批量改 heatmap

时间轨迹保留 line，离散大小保留 bar/dot，区间保留 forest，只有真实二维矩阵使用 heatmap。Portfolio 多样性不能成为换图理由，重复 heatmap 也要复核。

### 18. 满幅组成图在 100% 边界留白

关闭比例轴默认 margin 并锁定理论边界；Marimekko 同时锁定真实累计总量轴。标签向图内 annotation，不把上限改成 105%。

### 19. 有地名就画地图

先判断地理位置是否参与 Claim。只有距离/邻接/抽象关系时改用 network/matrix；区域强度比较补齐边界、唯一连接键和率/密度口径，点位检查 CRS 与经纬度顺序。不得依赖在线工具自动匹配来掩盖未匹配区域。

### 20. 把时间矩阵或普通横条称作 Gantt

先检查是否有资源、任务、start/end/duration。真正 Gantt 的条段必须对应资源占用区间，并从最终求解结果验证时长、no-overlap、precedence、release/due 与 makespan；缺少区间时改用 heatmap/table，不能手工挪条。

## 详细 Final QA

### 信息

- [ ] 一张图只有一个主要 Claim；Evidence 与 Chart Type 一致
- [ ] 决策顺序为“证据匹配 > 信息表达 > 可读性 > 全文多样性 > 高级感”
- [ ] 每张图已运行 Advanced Figure Candidate Gate；无实质增益时保留基础图
- [ ] Visual Information Density Gate 已为 `PASS`
- [ ] 互补证据已合理分层/分面，独立证据未硬拼，复合层均有核验职责
- [ ] Figure Portfolio Gate 已复核；重复图型若保留，确由相同证据结构支撑
- [ ] 连续多系列 line/bar 已平等复核 small multiples、matrix、dot/dumbbell、distribution；换图只由 Evidence 决定
- [ ] heatmap 只承担真实二维矩阵，不是避免重复的默认替代
- [ ] 高级候选有结构/信息增益；3D 满足双连续输入响应面合同
- [ ] Mosaic/残差气泡/Alluvial/Marimekko 确实多表达一个真实维度，否则 `KEEP_STANDARD`
- [ ] UpSet/Corrgram/Chord/Diverging 的成员、成对观测、边权或零点合同完整；Lollipop 确实降低阅读负担
- [ ] Map 只在地理位置/边界/空间路径支撑 Claim 时使用，且已与 heatmap、network、Sankey/alluvial 区分
- [ ] Scheduling/Gantt 有真实任务时段与资源占用，且已与时间矩阵、收敛图、流程图区分
- [ ] 连续曲线有足够真实点，未插值伪造
- [ ] 少量汇总指标未包装成“分布”
- [ ] 轴名、单位、图例、阈值/基准与数值精度完整

### 视觉

- [ ] 白底，主要颜色不超过约 5 个，无网红渐变或 3D 装饰
- [ ] 线宽、marker、网格、边框不过重，最终刻度可读
- [ ] 图例不遮关键区域；柱宽、组间距合理
- [ ] 主方案/对照/基准/改进/风险全文同色
- [ ] CI 在当前尺度清楚；边界标注不碰轴、刻度或裁切边界
- [ ] 满幅组成图比例轴精确贴合 0–100%，Marimekko 总量轴贴合真实边界
- [ ] 满幅边界标签向图内放置，未扩大坐标
- [ ] Map 的投影、范围、分级与色标可比，边界/点位/路线清楚且无敏感信息
- [ ] Gantt 的资源行、时间单位、任务标签、idle/setup 语义在最终宽度下可读

### 论文与模型证据

- [ ] 图题可直接进入正文，图内标题不重复，子图编号统一
- [ ] 图能被正文引用解释，不是装饰
- [ ] 预测有误差/残差；分类有混淆矩阵/ROC/PR；评价有排名/权重稳定性
- [ ] 优化有 baseline、敏感性或可行性证据；不确定性有区间或真实分布
- [ ] 声称下尾分布时确有样本并展示均值、VaR、CVaR 尾部
- [ ] 改进模型有 before/after 或 baseline 对比
- [ ] 地理图的 CRS、边界版本、连接未匹配、统计分母/单位已核验
- [ ] 排程图的 duration、资源不重叠、precedence、release/due、makespan 与求解状态已核验

### 输出

- [ ] 适合时保存 PDF 矢量版，并保存 400 dpi PNG
- [ ] 使用紧凑边界且无裁字；文件名有意义
- [ ] 图文件不含学校、队员或赛区信息
- [ ] 已按论文最终宽度渲染 A4 预览并实际打开
- [ ] 裁字、过粗、过密、过小、空白带或配色漂移已修改并复查
