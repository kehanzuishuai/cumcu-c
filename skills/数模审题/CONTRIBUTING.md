# 贡献指南

感谢改进“数模审题” Skill。它的核心目标是让赛题解读可回查、可验证、可复现，并且不替用户臆造题意或数值结果。

## 可以贡献什么

- 修正会导致漏问、错粒度、错单位、错时间轴或错误交付的规则；
- 增加能改变模型选择或验证结论的题型专项检查；
- 改进模板、输出 schema、验收量表和只读审计脚本；
- 增加不含真实竞赛材料的合成测试夹具。

## 修改原则

1. 把稳定的通用规则放在 `SKILL.md`，把只在特定题型或模式需要的细节放入 `references/`。
2. 事实、推论、主解释、可检验假设、备选解释和待计算结果必须保持分层。
3. 不把算法名称当成方案，不把未经运行的模型写成已验证结论。
4. 不提交原题 PDF、附件、优秀论文、个人数据、生成报告、绝对路径或密钥。
5. 脚本保持只读输入、显式输出；新增依赖需同步更新 `requirements.txt` 和 README。
6. 自动测试夹具和脚本依赖的路径使用 ASCII 文件名，中文语义写在文件内容中；发布 ZIP 前必须解压到新目录并从解压副本运行全部测试，避免跨平台文件名编码破坏夹具。

## 提交前验证

```bash
python -m unittest discover -s tests -v
python scripts/validate_interpretation.py tests/fixtures/minimal_report.md --expected-subproblems 1
```

如果改动了脚本，还应使用一个临时题目目录运行 `inventory_problem.py`，检查 CSV、JSON、PDF（若安装 `pypdf`）和大文件提示是否仍然正确。

## Pull Request 检查清单

- [ ] 说明改动解决的具体误读风险或维护问题。
- [ ] 新规则有最小合成测试或可复现的验证步骤。
- [ ] 没有引入真实竞赛材料或本机路径。
- [ ] README、参考文档和 `SKILL.md` 的目录链接仍然有效。
- [ ] 发布归档内没有 `#UXXXX` 转义文件名，解压副本中的全部测试通过。
- [ ] 未改变自动调用策略，除非 PR 明确说明原因。
