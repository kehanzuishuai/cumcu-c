# 小样本预测、评价与多变量模型路由

只在结构卡确认相应数据和任务后读取。所有权重、隶属函数、状态划分和降维维数都属于可验证模型设计，不得伪装成题面事实。

## 灰色预测 GM(1,1)

**适用任务/触发条件：** 等间隔、样本很少、数值为正且总体呈单调指数型趋势，目标是短期预测；它是小样本候选，不是见到“小样本”就自动采用。

**数据结构与前提检查：** 固定时间间隔和单位，检查原序列正值、异常点、趋势方向与结构突变。先计算级比 (\lambda(k)=x^{(0)}(k-1)/x^{(0)}(k))，对长度 n 的序列检查其是否大体落在 (e^{-2/(n+1)}<\lambda(k)<e^{2/(n+1)})；平移变换只能在有解释并回转量纲时使用。强季节性、明显周期或长期外推不宜直接用 GM(1,1)。

**朴素基线：** 最近值、历史均值、平均增长率或简单线性趋势；使用与 GM 相同的滚动起点和预测跨度。

**主模型/必要候选：** 前提可接受且优于基线时采用 GM(1,1)；趋势接近线性时保留线性回归，存在季节/充足样本时转 ARIMA/ETS/相应时间序列，机制明确时转差分/ODE。

**核心变量与数学结构：** 对原序列 (x^{(0)}) 做一次累加生成 (x^{(1)})，建立白化方程 (dx^{(1)}/dt+a x^{(1)}=b)，用背景值离散估计 a、b，再作逆累加还原预测。写清平移、背景值和还原过程。

**推荐求解方法/软件：** NumPy/SciPy 最小二乘即可；不需要为了模型名称引入黑箱库。保存原序列、级比、参数、拟合值和还原预测。

**必做验证：** 与朴素趋势基线做滚动/留后验证，比较 MAE、RMSE、WAPE 或适合小样本的相对误差；检查残差方向、级比、还原一致性和短期外推。后验差比/小误差概率可作辅助，不能替代样本外比较。

**灵敏度或稳健性：** 改变起止点、平移常数和最近一两个观测，观察参数和预测是否剧烈变化；报告预测跨度增长时的不确定性。

**常见误用：** 不检查级比；把任何短序列都视为灰色系统；为了通过级比任意平移却不还原；只报拟合误差；用 GM 做长周期或强季节预测；模型未优于简单趋势仍保留复杂名称。

**失败后的降级/替代方案：** 级比或滚动验证失败时回退最近值/线性趋势；有季节性转时间序列；数据极少且结构不稳时只给情景区间，不输出伪精确预测。

**与下一问可能的接口：** 输出预测期、点预测、误差区间/情景、数据版本和滚动验证结果；库存或优化问应接收需求情景/区间，而非只接一个点值。

## 模糊综合评价

**适用任务/触发条件：** 评价等级本身具有真实模糊边界，如“优/良/中/差”或安全等级，多个指标对等级的隶属程度有可审计依据，目标是综合隶属向量或等级而非精确概率。

**数据结构与前提检查：** 固定因素集、评价集、指标方向和尺度；说明隶属函数来自标准阈值、数据分布、专家标定还是实测校准。检查权重依据、专家人数与一致性、指标相关性和重复计权。若阈值完全清晰或不确定性可直接概率化，先用透明评分/概率模型。

**朴素基线：** 等权标准化评分、清晰阈值分类或 TOPSIS；与模糊评价使用同一指标和样本。

**主模型/必要候选：** 单层或多层模糊综合评价；只有层级真实存在时才做多层。权重可来自客观数据、经一致性检查的专家判断或二者组合，但必须做敏感性。若任务是效率边界则转 DEA，若是监督分类则转 Logistic/LDA 等。

**核心变量与数学结构：** 因素向量、评价集、权重 (A)、隶属矩阵 (R) 和合成 (B=A\circ R)。说明隶属函数形状、边界、归一化、合成算子及最终等级/分数的解模糊规则。

**推荐求解方法/软件：** NumPy/Pandas 即可；专家权重可结合 AHP 等，但一致性和来源必须单独报告。代码输出每项隶属度而非只输出最终等级。

**必做验证：** 检查每个样本的隶属度范围及行和、指标方向和极端值；与等权/清晰阈值基线比较；用已知样本、专家复核或留出标注检查等级合理性；检查权重、隶属函数和合成算子变化后的排名/等级稳定性。

**灵敏度或稳健性：** 系统扰动权重、阈值和隶属函数宽度，报告等级翻转区间；删去高度相关指标检查重复计权。

**常见误用：** 没有真实模糊性也套模糊评价；隶属函数凭空设定；把最大隶属原则当概率；权重和阈值不做敏感性；多层结构只为显得复杂；把评价结果写成因果结论。

**失败后的降级/替代方案：** 隶属依据不足时退回透明标准化评分/区间评价；有可靠标签时用监督分类并校准；专家意见不一致时报告区间或分组结果，不强行平均。

**与下一问可能的接口：** 输出完整隶属向量、最终等级/得分、权重和隶属函数版本、稳定性区间及翻转样本，供资源配置或风险排序使用。

## DEA 数据包络分析

**适用任务/触发条件：** 有多个同类决策单元 DMU，在可比生产/服务机制下使用多项投入产生多项产出，任务是相对效率、规模效率、投入冗余或产出不足评价。

**数据结构与前提检查：** DMU 必须同质、时间口径一致、投入产出方向合理且通常非负；检查样本量相对投入数 m、产出数 s 是否足以区分效率。`n >= max(m×s, 3(m+s))` 只能作经验诊断，不是硬定理。极端值、零值、负值和环境变量需单独处理，不能随意平移后忘记解释。

**朴素基线：** 单项产出/投入比、等权标准化效率或透明的成本—产出比；用于检查 DEA 排名是否只是某个单指标驱动。

**主模型/必要候选：** 规模报酬恒定且机制支持时用 CCR；规模差异明显或需分解纯技术/规模效率时用 BCC。根据控制能力选择投入导向或产出导向；只有题目确需进一步排序时才考虑超效率/交叉效率，并先处理可行性和稳定性。

**核心变量与数学结构：** 每个 DMU 的投入 (x_{ij})、产出 (y_{rj})、包络权重 λ、效率 θ/φ 和松弛变量；BCC 增加凸性约束。必须报告效率、参考集、投入冗余和产出不足，不能只给排名。

**推荐求解方法/软件：** 每个 DMU 解一个 LP，可用 HiGHS、SciPy linprog、Pyomo/PuLP、Gurobi/CPLEX；批量求解需保存状态和容差。

**必做验证：** 检查所有 LP 可行、效率边界与松弛；验证单位缩放不改变结论、支配关系不反转；比较 CCR/BCC 和投入/产出导向；对异常 DMU、删去单指标和重采样做稳定性检查。

**灵敏度或稳健性：** 扰动投入产出、删除极端 DMU、改变指标集和规模报酬假设，报告有效前沿和排名变化；需要统计不确定性时可 bootstrap，但须说明样本和计算限制。

**常见误用：** DMU 不同质；DMU 太少、指标太多导致几乎全有效；把坏指标当产出或方向颠倒；用 DEA 权重宣称因果重要性；只给效率排名不报告松弛和参考集；用任意平移处理负值。

**失败后的降级/替代方案：** 同质性不足时分组建模或转回归/随机前沿并控制环境因素；样本过少时减少有理论依据的指标或退回透明比率评价；超效率不可行时保留基础 CCR/BCC，不强行排序。

**与下一问可能的接口：** 输出 DMU 效率、规模效率、参考集、投入冗余、产出不足、稳定性区间和异常单元，供改进目标或资源配置问使用。

## 插值与函数拟合

**适用任务/触发条件：** 插值用于已知离散点之间补值、重建曲线/曲面；函数拟合用于含噪观测下估计趋势、参数或响应关系。两者任务不同，必须先判定是否允许穿过全部观测点。

**数据结构与前提检查：** 检查自变量排序、重复点、采样间距、边界、噪声、缺失机制和是否外推；二维/空间数据确认网格或散点结构。题面要求物理形状时检查单调、非负、凸性或守恒。

**朴素基线：** 最近邻/分段线性插值；拟合用常数、线性或低阶多项式。基线与主模型在相同留出点上比较。

**主模型/必要候选：** 平滑且网格规则可用三次样条；需保持单调和避免过冲时优先 PCHIP；高阶全局多项式仅在阶数低且证据充分时进入候选。含噪数据用线性/非线性最小二乘、样条回归或 GPR，按关系与不确定性需要选择；空间散点可用有验证的 RBF/克里金候选。

**核心变量与数学结构：** 明确节点、基函数/函数族、参数、损失、平滑惩罚和边界条件。插值误差与拟合残差分别报告，不把训练点零误差当泛化能力。

**推荐求解方法/软件：** SciPy interpolate/optimize、statsmodels、scikit-learn；保存节点、阶数/平滑参数、边界条件和训练数据 hash。

**必做验证：** 留一节点/交叉验证或留出区间比较误差；检查残差、边界、单调/非负/守恒和单位；改变网格或阶数检查稳定性；外推必须单独验证或标记高风险。

**灵敏度或稳健性：** 扰动节点、去除极端点、改变阶数、平滑强度和边界条件，观察曲线与下游积分/极值；空间模型检查采样密度影响。

**常见误用：** 用高阶多项式造成 Runge 振荡；对含噪数据强制插值；把插值当预测；超出数据范围仍称插值；只看 (R^2)；拟合函数违反物理边界。

**失败后的降级/替代方案：** 高阶不稳时退回分段线性/PCHIP/低阶样条；噪声大时转稳健回归或平滑；外推无证据时只给区间或拒绝输出。

**与下一问可能的接口：** 输出可复现函数/插值器、参数、有效区间、误差和边界条件，以及下游真正需要的积分、导数、极值或网格值。

## PCA、因子分析、PLS、CCA 与 LDA 选择路由

**适用任务/触发条件：** 多变量高度相关或维数较高，需要无监督压缩、潜在因子解释、有监督预测、两组变量关联或有标签线性判别之一；先明确任务，不能把五种方法当可互换降维工具。

**数据结构与前提检查：** 样本行和变量列必须明确，训练/验证隔离，量纲差异时在训练折内标准化。检查缺失、异常、变量类型、样本量与协方差可估性。PCA 只最大化 X 方差；因子分析假设潜变量解释共同相关；PLS 需要响应 Y；CCA 需要两组变量 X/Y；LDA 需要可靠类别标签并近似满足类内协方差结构。

**朴素基线：** 标准化原变量、少数业务核心变量，或 Ridge/Logistic 等直接监督模型；降维必须证明改善验证、稳定性或解释，而非只减少列数。

**主模型/必要候选：** 无监督方差压缩用 PCA；解释潜在构念用因子分析；多重共线且目标是预测 Y 用 PLS；研究两组变量的线性关联用 CCA；有标签线性判别用 LDA。类协方差明显不同且样本足够时比较 QDA；纯特征筛选可比较正则化模型。

**核心变量与数学结构：** 固定中心化/标准化、成分/因子数、载荷/得分、监督响应或类别。因子分析说明旋转；PLS/CCA/LDA 的所有预处理和维数选择必须在训练折内完成。

**推荐求解方法/软件：** scikit-learn、statsmodels/factor_analyzer 或 R 对应包；保存缩放参数、载荷、解释方差/共同度、交叉验证维数和随机种子。

**必做验证：** PCA 用解释方差、重构误差和载荷重采样稳定性；因子分析用 KMO/Bartlett、平行分析、共同度和旋转稳定性；PLS 用嵌套交叉验证预测误差；CCA 用置换/重采样检验典型相关稳定性；LDA 用分层交叉验证、混淆矩阵、校准和协方差诊断。所有方法检查数据泄漏。

**灵敏度或稳健性：** 改变标准化、成分/因子数、异常点和变量子集，观察载荷、预测、相关或分类结果；符号翻转不应误判为结构变化。

**常见误用：** PCA 成分被直接命名为真实潜因果；先全数据降维再交叉验证；用 PCA 代替监督特征选择；没有 Y 却用 PLS；CCA 高维小样本产生虚高相关；LDA 标签不可靠或协方差奇异仍直接使用。

**失败后的降级/替代方案：** 载荷/维数不稳时保留原变量或正则化；因子结构不成立时回退 PCA/透明指标；PLS 无预测增益时用 Ridge；CCA 不稳时报告变量级相关并校正多重检验；LDA 前提失败时比较正则化 LDA、Logistic、QDA 或树模型。

**与下一问可能的接口：** 输出预处理器、载荷/得分或监督预测器、保留维数及稳定性；下游必须使用同一缩放和训练期参数，不能重新在全数据上拟合。

## 聚类模型选择与验证

**适用任务/触发条件：** 无可靠标签但需要发现相似群组、典型模式或异常簇，并且分组结果会服务解释或下游决策；若已有标签且目标是预测类别，应走分类路线。

**数据结构与前提检查：** 明确样本粒度、变量类型、尺度、距离含义、缺失和异常。连续近球形簇、任意形状/噪声、椭球概率簇、层级结构和混合类型数据需要不同模型。检查样本是否有时间/空间/主体依赖，避免泄漏。

**朴素基线：** 单簇、业务规则分组或标准化后的 K-means；用于判断复杂聚类是否真正提供稳定结构。

**主模型/必要候选：** 连续、近球形且规模较大用 K-means；需要层级解释且样本可控用层次聚类；任意形状和噪声用 DBSCAN/HDBSCAN；椭球簇和软分配用 GMM；混合类型可用 Gower 距离层次聚类或有依据的 k-prototypes。候选不超过结构证据支持的少数路线。

**核心变量与数学结构：** 固定特征、缩放、距离、簇数/密度参数、初始化和噪声定义；若先 PCA，再把 PCA 作为训练管道一部分并记录维数。

**推荐求解方法/软件：** scikit-learn、hdbscan 或 scipy.cluster；使用管道保存预处理、参数、随机种子和标签映射。

**必做验证：** 同时检查内部指标（轮廓系数、Calinski-Harabasz、Davies-Bouldin 中适用者）和扰动/重采样/不同初始化后的稳定性；比较簇规模与可解释性；有独立标签时才用 ARI/NMI 等外部指标。下游决策必须做“聚类前后是否改善”的任务验证。

**灵敏度或稳健性：** 改变缩放、距离、簇数、密度参数、异常处理和随机种子，报告样本归属/簇特征稳定性；时序数据用分时段复现。

**常见误用：** 只看二维图或肘部法；把 K-means 用于类别/混合变量而无距离依据；只跑一个随机种子；用轮廓系数宣称业务真类；把噪声点强塞入簇；先全数据降维造成泄漏。

**失败后的降级/替代方案：** 稳定簇不存在时诚实报告连续谱或无可靠分群，退回描述统计/降维；密度参数敏感时保留层次结构或区间；下游无增益时不使用聚类标签。

**与下一问可能的接口：** 输出预处理器、模型参数、样本簇/噪声标签、簇画像、稳定性分数和不确定归属；下游按固定模型分配新样本，不得重排簇号后混用。
