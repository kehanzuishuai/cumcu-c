# 题型专项检查

只读取与当前题目有关的部分。混合题可能需要多个部分。

## 模型路由与验证的共同规则

模型路由发生在题意、粒度和 HARD 约束已明确之后。下列方法选择属于 `MODEL_DESIGN` 或普通模型假设，不得倒推改变题面事实，也不得因为存在多种可行算法就新建 `BLOCKING` 歧义。

每个实际启用的路线至少记录：触发它的数据/机理证据、简单基线、主模型与必要备选、数学结构、匹配的求解器或估计方法、评价指标、验证规则和失败后的回退。复杂模型只有在基线暴露出可核验缺口时才升级。

先读取 `model-routing-tree.md`，填写六维结构卡并缩小候选集，再只读相关专项：

- 图/网络、排队、马尔可夫、库存、目标规划、动态规划、调度、稳态或差分结构：`operations-state-routes.md`；
- GM(1,1)、模糊综合评价、DEA、插值/拟合、多变量投影与聚类：`data-evaluation-routes.md`；
- 精确模型在比赛时限内失效或结构确为非凸/黑箱时：`heuristic-routing.md`。

上述专项统一使用“适用任务/触发条件 → 数据结构与前提检查 → 朴素基线 → 主模型/必要候选 → 核心变量与数学结构 → 推荐求解方法/软件 → 必做验证 → 灵敏度或稳健性 → 常见误用 → 失败后的降级/替代方案 → 与下一问可能的接口”。动作词只辅助定位，不能越过结构和前提检查直接套模型。

### 评价指标路由速查

指标按任务输出、数据结构和错误代价选择，不要求一问堆齐全部指标。候选模型必须使用相同的数据划分、预测跨度、单位和统计口径比较；没有题面、数据或文献依据时，门槛写 `待校准`。

| 任务 | 主比较/验证指标 | 必须同时检查 |
| --- | --- | --- |
| 回归/混合模型 | AIC、BIC、验证 RMSE/MAE、边际/条件 \(R^2\) | 系数置信区间、残差结构、参数稳定性；重复测量不得按独立样本评价 |
| 时间序列预测 | 滚动或扩展窗口 MAE、RMSE、MAPE、WAPE | 与季节均值/ARIMA 等基线同口径比较；零值较多时不单独依赖 MAPE；检查残差 ACF/白噪声和多步误差 |
| 分类 | 混淆矩阵、Precision、Recall、F1、ROC-AUC、Brier | 类别不平衡时优先看 PR-AUC；筛查/高风险判定补 Sensitivity、Specificity、PPV、NPV，并检查阈值敏感性 |
| 生存/时点 | 对数似然、AIC/BIC、C-index | 校准、残差及相应比例风险或分布假设；删失结构必须进入评价口径 |
| 聚类 | 轮廓系数 | 扰动、重采样或不同初始化后的分组稳定性，不能只凭可视化宣布聚类有效 |
| 综合评价/排序 | 权重敏感性、排名稳定性 | 等权或其他简单评分基线、删去指标后的变化、指标相关性与重复计权风险 |
| 图/网络 | 路径/建网成本、流量或匹配目标 | 逐边回放、连通/无环、流守恒、容量、匹配唯一性；最大流补最小割对照 |
| 排队 | 等待时间、队长、等待概率、服务成本 | 稳定条件、Little 定律、实测/离散事件仿真对照及高峰情景 |
| 马尔可夫链 | 一步/多步概率误差、Brier/log loss 或状态占比误差 | 转移矩阵行和、齐次性、状态可达性、稳态/吸收概率 bootstrap 稳定性 |
| 库存 | 总成本、缺货率、满足率、周转 | 库存平衡、提前期/容量、需求预测误差传播及成本参数敏感性 |
| DEA/模糊评价 | 相对效率/松弛或综合隶属/等级 | DMU 同质性与前沿稳定性，或隶属函数依据、行和与权重/阈值敏感性 |
| 调度/动态规划 | makespan、延期、价值或累计成本 | 工序/资源可行性、小实例精确对照、bound/gap，或 Bellman 残差/策略回放 |
| 稳态/差分 | 平衡残差、状态轨迹和关键事件误差 | 守恒/可达/稳定性、初值与参数敏感性、时间步或网格收敛 |
| 优化/启发式 | 目标值、约束满足/可行率、相对基线改善、求解时间 | 重复运行均值/标准差；求解器可提供时报告下界、上界或 optimality gap |
| 随机/风险 | 均值、标准差、分位数、置信区间 | 随机种子/重复次数、样本数收敛、分布或区间依据及替代情景 |
| ODE 动态系统 | 状态轨迹或关键事件误差 | 初值/边界、非负性与守恒、步长/求解精度收敛、关键参数扰动 |

## 机理、几何与运动

检查：

- 坐标原点、坐标轴、投影约定和单位；
- 点、有限线段、面、实体之间是否被错误简化；
- 释放、碰撞、切换、到达等事件处的状态连续性；
- 决策点是否由真实轨迹或流程可达；
- 边界条件、守恒和极限情况；
- 连续事件与时间网格近似；
- 题目要求碰撞/覆盖实体时，不能只检查中心点或把手点。

最低验证：确定性锚点、约束回放、时空离散收敛和独立几何/仿真复核。

### 微分方程模型路由

只有当题目存在连续状态演化，且变化率能由守恒、流量、转移率或其他当前状态关系给出时，才把常微分方程（ODE）列为主模型候选。需要预测状态轨迹、稳态、阈值到达时间或干预响应，但只有历史时间序列而没有速率机制，并不足以自动路由到 ODE。

| 证据结构 | 优先路线 | 方案中必须固定 |
| --- | --- | --- |
| 连续状态 + 可写出的变化率/守恒关系 | ODE；Euler 可作透明数值基线，RK4 或可靠数值积分作主求解候选 | 状态变量、时间单位、导数关系、参数来源、初值、边界/事件条件和外部输入 |
| 按固定时段跳变且转移规则天然离散 | 差分方程、状态转移或离散事件模型优先 | 时间步含义、更新顺序、同步/异步事件和离散误差 |
| 只有观测序列，目标是样本外预测 | 时间序列/回归预测优先 | 训练—验证切分、预测跨度和误差指标；除非另有速率机制证据，否则不把拟合曲线解释为 ODE |
| 只求静态平衡、配置或最优方案 | 代数方程、统计模型或优化优先 | 平衡条件、目标和约束；不为增加模型复杂度引入无必要导数 |

ODE 路线的最低验证为：减小步长或提高求解精度后关键输出稳定；初值和边界条件可回查；非负性、守恒或已知极限不被破坏；关键参数扰动有结果边界。若参数无法由附件、文献或数据识别，必须降级为区间/情景分析或更简单的经验模型，不能把不可识别参数包装成已估计结果。

## 概率、抽样与质量决策

检查：

- 原假设/备择假设、单侧/双侧规则和“信度”的精确定义；
- 两类错误、功效、接收和拒收边界；
- 共享潜在状态导致的事件依赖；
- 条件与无条件次品率/命中率；
- 返工、拆解、退回循环的递归期望成本；
- 参数不确定性是否传入下游决策。

最低验证：概率上下界和极限、解析与数值/蒙特卡洛交叉核验、决策敏感性、统一收益或损失口径。

## 统计、重复测量与时间序列

检查：

- 行级记录与主体级分析单位；
- 重复测量、批次、采样频率和删失；
- 时间泄漏、主体泄漏、价格或处理的内生性；
- 不规则采样、缺失机制、聚合和积分单位；
- 趋势/季节性引起的伪相关；
- 校准、不确定性和外推边界。

最低验证：按主体隔离或滚动时间验证、残差/诊断、清洗与插补敏感性、不确定区间。

### 统计与回归候选模型路由

坚持“数据结构 → 简单基线 → 诊断 → 有依据升级”。不得先列模型清单再逐个试，也不得为迁就正态似然、独立性或计算量而无证据改变题面粒度、删除关键零值或聚合观测。下表只决定何时进入候选；最终主模型仍由同口径验证决定。

| 方法 | 进入候选的数据结构/任务 | 简单基线 | 必须验证 |
| --- | --- | --- | --- |
| Bayesian/MCMC | 有可辩护先验或层级信息，且任务需要完整参数/预测不确定性；小样本只有在先验可审计时才构成理由 | 与同一似然对应的 MLE、GLM/LMM 或经验基线 | 似然与响应支持匹配；多链轨迹、R-hat、ESS/MC 误差、先验敏感性、后验预测检查和样本外表现 |
| Poisson GLM | 非负整数计数或带暴露量的发生率，条件均值随协变量变化 | 总体/分组平均率或简单线性模型 | 暴露量/offset、过度离散、零膨胀、偏差残差和样本外计数误差；失配时不能强留 Poisson |
| Logistic GLM | 二分类或二项比例，需要可解释的条件概率 | 多数类/固定概率规则或无交互 Logistic | 分层/主体隔离验证、校准与 Brier、ROC/PR、阈值敏感性、分离问题和类别不平衡 |
| Gamma GLM | 响应严格为正、连续且右偏，方差随均值增大 | OLS 或 log-OLS | 零/负值排除依据、链接函数与离散参数、偏差残差、样本外 MAE/RMSE 和区间校准 |
| 分位数回归 | 关注中位数/上下尾部，或效应随条件分位数变化、异方差明显 | OLS 与常数中位数预测 | 样本外 pinball loss、分位覆盖率、不同 \(\tau\) 的系数稳定性、区间估计和分位数交叉 |
| 稳健回归 | 少量高影响观测使 OLS 系数/残差明显不稳，但研究目标仍是中心关系 | OLS | 影响诊断、含/不含高影响点的系数与预测稳定性、稳健损失敏感性及样本外误差；不能用它掩盖数据错误 |
| Elastic Net | 预测变量较多且强相关，同时需要正则化与有限变量筛选 | OLS、Ridge、Lasso | 标准化、训练折内/嵌套调参、留出误差、系数选择稳定性；选择后显著性不作为唯一证据 |
| GPR | 小到中等样本、低维平滑非线性关系，且预测区间本身影响决策 | 线性/样条回归或相应时间序列基线 | 留出 RMSE/MAE、预测区间覆盖、核与超参数敏感性、输入尺度、计算规模和外推失效边界 |
| LMM | 连续响应存在重复测量/主体或批次聚类，需要主体特异效应，固定效应关系近似线性 | 忽略聚类的 OLS 与仅固定效应模型 | 按主体切分、随机效应/协方差结构必要性、残差、ICC、边际/条件 \(R^2\) 和参数稳定性 |
| NLME | 重复测量轨迹具有可解释的非线性形态，且个体在曲线参数上存在差异 | 非线性最小二乘与较简单 LMM | 函数形式依据、初值与可识别性、收敛、随机参数协方差、按主体样本外预测和替代曲线敏感性 |
| GEE | 聚类/重复观测下关注总体平均效应，而非个体随机效应分布 | 忽略聚类的 GLM 或独立工作相关 GEE | 聚类数、稳健标准误、工作相关结构敏感性、QIC/样本外表现；需要个体特异推断时与 LMM/相应混合模型比较 |
| VIKOR | 多指标排序同时关心总体效用与最差指标遗憾，并需输出妥协方案 | 等权评分或 TOPSIS | 指标方向/归一化、权重与妥协参数敏感性、排序稳定性、可接受优势/稳定条件及下游决策变化 |
| QDA | 有标签分类中各类协方差结构明显不同、边界可能为二次型，且每类样本足以估计协方差 | Logistic 与 LDA | 分层交叉验证、协方差估计稳定性/正则化、类别不平衡指标、校准；高维小样本时回退基线 |
| GARCH | 均值模型残差存在波动聚集/条件异方差，任务需要波动或风险区间 | ARIMA/ETS 等恒定方差均值模型 | 平方残差相关/ARCH 证据、标准化残差、阶数与误差分布敏感性、样本外波动损失和区间覆盖 |
| 无监督异常检测 | 缺少可靠异常标签，异常可能是多变量、局部或非线性结构 | 业务硬规则与 IQR/MAD 等单变量规则 | 人工抽样/已知约束或合成注入核验、污染率/超参数稳定性、不同方法一致性及清洗前后下游结论；无标签时不虚报 Accuracy/F1 |

### 统计检验细化路由

先按样本是否独立、变量类型、分布条件、时间/删失结构选择检验，不默认只做 t 检验。检验计划应写明原假设/备择假设、单侧或双侧、分析单位、显著性水平来源、效应或相关方向、置信区间以及结论不成立时的模型处理。

| 数据/问题结构 | 候选检验或模型 | 关键防错 |
| --- | --- | --- |
| 连续结果的参数比较，参数检验条件可接受 | 与设计匹配的 t 检验；多组比较用 ANOVA | 先区分独立、配对或分组结构；显著性不能替代效应量、区间和样本外表现 |
| 两个独立样本，连续/有序结果不满足参数条件 | Mann–Whitney U / Wilcoxon 秩和检验 | 不能与配对 Wilcoxon 符号秩混用；解释为分布/位置差异时核对分布形状与独立性 |
| 三个及以上独立样本不满足 ANOVA 条件 | Kruskal–Wallis 检验 | 显著后另做有校正的事后比较；不能直接断言所有组两两不同 |
| 配对或同一对象前后比较，参数条件不足 | Wilcoxon 符号秩检验 | 保留配对关系，不能拆成两组独立样本 |
| 同一对象在三个及以上条件/时点重复测量，参数条件不足 | Friedman 检验 | 保留区组/主体对应；显著后采用配对事后比较并做多重校正 |
| 回归/组间比较需要检查正态前提 | Shapiro–Wilk + Q-Q 诊断 | 优先检查模型残差或组内分布，不因原始响应边际非正态就否定全部回归；大样本时不只看 p 值 |
| 组间比较需要检查方差齐性 | Levene；近似正态时可用 Bartlett 方差齐性检验 | Bartlett 对非正态敏感；不齐时改用异方差稳健路线，不能为通过检验删数据 |
| 分类变量之间的关联 | 卡方检验 | 单元格计数和分析单位必须与列联表口径一致，不把相关写成因果 |
| 连续变量的线性或一般单调关系 | Pearson 或 Spearman | 根据线性、尺度和异常值选择；趋势/季节性可造成伪相关 |
| 有序等级、秩次关系、小样本或并列秩较多 | Kendall 秩相关 | 与 Spearman/Pearson 基线同口径比较，报告区间/重采样稳定性，不把单调关联写成因果 |
| 存在共同混杂因素 | 条件/控制相关 | 明确控制变量及其来源；只作有边界的关联解释 |
| 同时检验多组变量或多重比较 | 在原检验后做多重检验校正 | 预先声明检验族和校正口径，不能只报告筛出的显著项 |
| 时间序列关系 | 平稳性与自相关检查 | 先处理趋势、季节和滞后结构，再解释相关或回归结果 |
| 区间删失的时点/首次达标数据 | 区间删失 AFT 等与删失结构匹配的方法 | 不把删失时点当成精确事件时点；同时核查分布假设 |

统计检验只是验证链的一部分。候选模型仍需在统一口径下比较 AIC/BIC、验证误差或任务指标，并结合残差与假设诊断；不能仅凭 `p < 0.05` 冻结主模型。

## 优化、排程与资源配置

检查：

- 哪些量真实可控；
- 硬约束、惩罚和偏好的区别；
- 离散/连续变量与不可行解修复；
- 滚动窗口、最小批量、间距、轮作、容量和跨期状态；
- 重叠/覆盖是否按并集而非重复相加；
- 多目标聚合和最差情形；
- 决策先于随机结果时的非预见性。

最低验证：可行基线、完整约束检查器、稳定性/最优性证据、压力情景和结果模板回放。

### 优化求解器与工程化路线

先由变量类型、约束形式和目标函数确定 LP/MILP/NLP/MINLP 或约束规划结构，再选工具；不得先选算法名再改写模型迎合求解器。

| 数学结构 | 优先求解路线 | 必须报告的证据 |
| --- | --- | --- |
| LP | HiGHS、Gurobi、CPLEX、LINGO 等线性规划求解器 | 最优状态、目标值、原始可行性；可获得时记录上下界 |
| MILP | HiGHS、SCIP、Gurobi、CPLEX 等混合整数求解器 | 整数/逻辑变量实现、全部约束回放、下界/上界或 optimality gap、时间限制 |
| 逻辑和排程占主导的整数问题 | CP-SAT/OR-Tools 或等价 MILP，按表达紧凑性和规模比较 | 逻辑约束的等价性、可行解、停止条件及有界最优性证据 |
| 光滑连续 NLP | scipy/fmincon 或支持相应 NLP 的求解器 | 初值、边界、终止条件；非凸时用多初值/基线检查局部解稳定性 |
| MINLP 或复杂非凸模型 | 仅使用明确支持当前结构的求解器；否则采用分解或启发式作为有边界的近似 | 不宣称未经证明的全局最优；报告可行性、基准/下界差距和重复运行稳定性 |

规模过大时可以使用候选集剪枝、滚动窗口、分层或分解，但每项工程化处理必须记录：触发原因、压缩规则、压缩前后规模、是否保持全部 HARD 约束、可能损失的最优性以及用于核对的小规模精确算例。GA、PSO、SA、ACO、Tabu、NSGA-II 等只作为精确结构在规模/非凸/黑箱条件下失效后的备选；按 `heuristic-routing.md` 选择与解空间匹配的单一路线或必要对照，并强制多随机种子、可行率、基线及小规模精确解/上下界比较，不能只画收敛曲线。

### 多目标方法路由

先统一目标方向、单位和尺度，写清最终如何从非支配方案中选出一个可交付折中方案。多目标方法的选择属于模型设计，不得把权重或 \(\varepsilon\) 值伪装成题面规定。

| 结构与目的 | 优先候选 | 使用边界与验证 |
| --- | --- | --- |
| 权重有依据、需要一个易解释折中解 | 加权和基线 | 做权重敏感性；目标尺度差异大时先归一化；非凸/离散前沿可能被漏掉 |
| 有明确主目标，其他目标可转成可解释上/下界 | ε-约束法 | 先由单目标极值或 payoff table 确定可行 ε 范围，再系统扫描；记录不可行情形和 ε 步长敏感性 |
| 需要较完整地枚举离散/MILP 的有效前沿，并减少普通 ε-约束的弱有效解或重复解 | AUGMECON2 | 记录主目标、受约束目标、增广项、目标范围、网格和停止规则；最终折中选择与前沿生成分开说明 |
| 非线性、非凸或黑箱问题，精确枚举困难 | Pareto/NSGA-II 等候选 | 先通过 `heuristic-routing.md` 的精确优先门禁；详细编码和多种子验收只在该专项维护 |

共同最低验证：所有候选均满足 HARD 约束；输出确为非支配方案；权重/ε/网格扰动后主要折中关系不翻转；最终选中方案的选择规则可复现。若高级方法没有比加权和基线提供额外的可行折中信息，应保留更简单路线。

## 动态网络与路径

具体的 Dijkstra/Floyd/Bellman-Ford、Prim/Kruskal、最大流、最小费用流、二分图匹配/指派和选址—配送选择规则见 `operations-state-routes.md`。本节保留动态网络的额外致命检查。

检查：

- 边内部点是否插入虚拟节点，而非吸附端点；
- 边的可用性、方向、速度和等待是否随时间变化；
- 同时事件、汇流、环路、优先级和守恒；
- 使用普通时间依赖 Dijkstra 前是否满足 FIFO；
- 重规划时使用实际位置，包含通知前已发生的移动；
- 无安全路径或无可行方案输出。

最低验证：可手算小网络、守恒、事件/步长收敛和逐边路径回放。

## 视频、图像与小样本学习

检查：

- 帧率、坐标方向、画面边界和关键点缺失；
- 二维投影以及缺少尺度、深度或力测量的限制；
- 试次与参与者的独立性；
- 按主体隔离验证和特征选择泄漏；
- 代理标签与独立真值的区别；
- 训练建议只能写成有界关联/反事实，不能无证据写因果。

最低验证：人工关键帧样本、平滑/尺度敏感性、留一主体验证、代理误差和分布外弃权。

## 大日志、轨迹与政策评价

检查：

- 编码、文件大小、分块/流式读取和重复记录；
- 标识符、时钟一致性和合理旅行时间；
- 未观测转向、中途出现/消失或其他潜在状态；
- “巡游”“拥堵”“接受管控”等操作定义和阈值敏感性；
- 政策评价是否有可比基线或反事实；
- 同期事件、选择偏差和趋势变化。

最低验证：人工抽样审计、流量/轨迹一致性、阈值敏感性、资源估算和带不确定性的政策比较。
