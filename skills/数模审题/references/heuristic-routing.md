# 启发式算法选择与验收

本文件只在精确结构已识别、但规模或非凸/黑箱性质使精确求解不能在比赛时限内完成时读取。若存在可直接表达的 LP、MILP、网络流、动态规划或 CP-SAT 结构，应先运行相应精确求解器；启发式不得因“代码熟悉”而优先。

## 启用门禁

进入启发式前必须保存：

- 原始精确数学结构、变量域和全部 HARD 约束；
- 一个快速可行的构造基线；
- 小规模精确解或可用的上下界/松弛界；
- 选择启发式的规模、非凸或黑箱证据；
- 时间预算、停止规则，并明确不得宣称全局最优。

## GA、PSO、SA、ACO、Tabu、NSGA-II 路由

**适用任务/触发条件：** 精确模型已建立但在给定规模/时限内难以求解，或目标/约束由不可微仿真和黑箱评价给出；需要在可行解空间内搜索高质量近似解。

**数据结构与前提检查：** 固定连续、整数、0-1、排列、路径或混合编码；确认目标能稳定计算、HARD 约束可检查、邻域/修复不会改变题意。多目标问题先判断加权和、ε-约束、AUGMECON2 是否可行。随机目标需统一随机数或足够重复，防止噪声驱动选择。

**朴素基线：** 随机可行搜索加一个与结构匹配的构造/贪心规则；同时保留小规模枚举/精确求解器或 LP 松弛界。没有这些基线，不得只比较不同启发式名称。

**主模型/必要候选：**

| 解空间/搜索困难 | 优先候选 | 进入理由与排除条件 |
| --- | --- | --- |
| 组合、0-1、排列或混合编码，需要群体搜索 | GA | 编码、交叉和变异能保持或可靠修复可行性；若 MILP/CP-SAT 可在时限内给出 gap，则精确解优先 |
| 有界连续变量、目标可数值评价、维度中等 | PSO | 位置/速度更新与边界处理自然；离散排列问题不要生硬连续化 |
| 有明确邻域的单解组合或非凸问题，需要允许暂时劣化跳出局部最优 | SA | 温度、邻域和降温可解释；若简单多初值 NLP 已稳定，不再增加 SA |
| 路径、排列、路由等可由逐步构造表示 | ACO | 信息素和启发项与边/转移相关；一般连续问题不优先 |
| 离散邻域搜索易循环、需要记忆近期动作或属性 | Tabu | 禁忌表、特赦规则和邻域规模可定义；没有自然邻域时不采用 |
| 两个及以上冲突目标、前沿非凸/黑箱且精确多目标方法困难 | NSGA-II | 需要一组非支配近似解；若 ε-约束/AUGMECON2 可稳定生成有效前沿，则精确路线优先 |

不要为了“模型丰富”并列运行全部算法。通常只保留一个结构最匹配的主启发式和至多一个具有不同搜索机制的必要候选。

**核心变量与数学结构：** 明确编码—现实决策的一一映射、适应度/目标、约束检查器、修复或可行性保持算子、邻域/群体更新、精英保留、停止规则。罚函数不能替代题面 HARD 约束；若使用罚项，必须证明最终输出仍逐项可行。

**推荐求解方法/软件：** 优先在现有精确模型和约束检查器上封装搜索；可用 DEAP、pymoo、PyGAD、scikit-opt 或自写实现。版本、随机种子、种群/邻域规模、迭代上限、时间预算和全部关键参数必须落盘。

**必做验证：** 至少多个独立随机种子，报告最佳/中位/最差、均值/标准差、可行率和求解时间；逐项回放全部 HARD 约束；与构造基线、小规模精确解、下界/上界或求解器 incumbent 比较。多目标还要检查非支配性、前沿覆盖/稳定性及最终折中选择规则。收敛曲线只能作为运行诊断，不能单独证明正确或最优。

**灵敏度或稳健性：** 改变随机种子、种群/邻域规模、迭代/时间预算、罚项/修复规则和关键算法参数；对输入需求、成本、容量或黑箱噪声做情景扰动。若推荐决策频繁翻转，报告候选集或保守方案。

**常见误用：** 有精确 LP/MILP/网络流/CP-SAT 却直接上启发式；只给一条下降曲线；不报告不可行个体比例；用巨额罚函数掩盖约束违反；把单次最好值写成稳定结果；不同算法使用不同时间/评价次数；NSGA-II 只画前沿却不验证非支配与可行性；宣称全局最优。

**失败后的降级/替代方案：** 可行率低先改用可行编码、修复或分解，不盲目调参；结果不稳定时增加重复、缩小决策空间或回退构造基线；性能不超过基线时保留简单方案；时间不足时输出当前可行 incumbent、与界/基线的差距和未证明最优声明。

**与下一问可能的接口：** 输出固定种子集合、参数表、每次运行的目标/可行性/时间、最佳与中位方案、精确小实例或 bound 对照、最终方案文件和不稳定决策集合；下游不得只接收“最优适应度”。

## 与精确模型的双轨交付

启发式不是新的题意或另一套目标。最终模型方案应同时保留：

```text
精确数学模型与 HARD 约束
  -> 小规模精确解/松弛界
  -> 启发式编码与可行性保持
  -> 多种子结果分布
  -> 与基线和精确证据的差距
  -> 有边界的最终结论
```

只要精确求解器在比赛时限内恢复可接受 gap，就应优先交付精确结果；启发式可保留为规模扩展或稳健性对照。
