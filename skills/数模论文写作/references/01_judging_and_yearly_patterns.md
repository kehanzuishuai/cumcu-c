# 第一篇：评委视角下的 C 题高分逻辑

## 1.1 评委不是在找“唯一正确模型”，而是在统一评阅要点下判断完整性与可信度

全国评阅并不是每位评委凭个人偏好随意看论文。正式评阅前，评阅组会围绕赛题、评阅要点和可能的解题思路进行讨论，必要时先试评若干篇论文，再形成可操作的评阅细则。对申报本科组全国一等奖的论文，至少由 3 位评委独立评阅。

这意味着：

- 你不需要猜“命题人唯一想要哪一个模型”；
- 你需要确保自己的方案能经得起多位评委从不同角度检查；
- 一个“冷门高级算法”无法替代模型合理性、结果正确性和表达清楚；
- 真正有价值的创新必须能被评委在正文中**识别、验证、解释**。

## 1.2 评审可以抽象成五道关卡

### 关卡 0：规则与格式没有硬伤

正式国赛论文首先要满足组委会格式、支撑材料与 AI 使用要求。对 2026 备赛尤其要记住：

- 摘要专用页“标题 + 摘要 + 关键词”原则上不超过 1 页；
- 正文不要目录，正文不超过 30 页，附录页数不限；
- 电子论文为单个 PDF/Word 文件（建议 PDF），不超过 20 MB，电子版第一页必须是摘要页；
- 支撑材料单独 RAR/ZIP 压缩，不超过 20 MB；
- 附录必须列出支撑材料文件清单，并包含全部完整、可运行源程序；Excel、SPSS 等交互命令也应纳入；
- 引用公开资料必须在正文具体位置标注，并列入参考文献；
- 摘要、正文、附录、支撑材料、代码和文件名均不得出现身份、学校或赛区信息；
- 使用 AI 时，必须在参考文献之前加入“AI 工具使用声明”，并在支撑材料中提供 `AI 工具使用详情.pdf`；
- 程序缺失、程序不能运行、结果与论文不符、支撑材料不一致、AI 使用故意隐瞒或未经人工核验等，都可能产生严重资格风险。

> **因此：本手册可以有导航目录，但正式参赛论文不得照搬目录；任何排版经验都不能覆盖组委会的提交硬规则。**

### 关卡 1：摘要与整体结构能否让人迅速抓住主线

评委进入正文前，需要在摘要里知道：

- 你把每问识别成了什么数学任务；
- 你用了什么核心模型/算法；
- 关键改进是什么；
- 得到的量化结果是什么；
- 最终方案是否可执行、是否经过检验。

摘要若只有“本文建立某模型，效果较好”，评委无法判断你到底解决到什么程度。

### 关卡 2：模型是否对题、约束是否完整

C 题最常见的失分不是不会高级算法，而是：

- 数据结构判断错；
- 把题目明确给出的业务/物理约束漏掉；
- 用模型方便性替代实际合理性；
- 问题一、二、三互相独立，前一问结果没有进入后一问；
- 目标函数写得漂亮，但决策变量与约束无法对应实际动作。

### 关卡 3：结果是否正确、可信、可复现

评委会关注：

- 结果是否满足所有硬约束；
- 表格是否完整填入题目要求的结果模板；
- 正文数字、图表、支撑文件是否一致；
- 预测是否有误差；分类是否有混淆矩阵；优化是否有可行性核验；随机算法是否重复运行；
- 结果是否具有实际含义，而不是只报告“目标函数 = 123.456”。

### 关卡 4：创新是否自然、表达是否清楚

创新不是“换一个更少见的算法名称”，而通常来自：

- 数据结构识别更准确；
- 关键现实因素被合理加入；
- 约束建模更严谨；
- 基础模型存在缺陷后进行了有证据的修正；
- 不确定性处理更合理；
- 给出了风险—收益、精度—复杂度等可解释权衡；
- 结果更可执行、更稳定。

## 1.3 五关评审下，C 题论文的“页面资源”应该怎么分配

评审流程截图最有用的地方，不是让我们猜评委到底看几分钟，而是提醒我们：**高价值内容必须有较高的信息密度。**

### 第一屏：摘要页

四问题型优先采用“**开头 + 四问 + 结尾创新点**”六段式，整体信息量建议占摘要页约 **3/4—1 页**；关键词与摘要正文之间空一行。必须出现：

- 每问任务本质；
- 核心模型/算法；
- 一到两个关键处理（如“不确定性用 CVaR”“重复测量用 LMM”“不重茬用 0-1 变量线性化”）；
- 关键量化结果；
- 至少一句验证/对比结论。

摘要里不值得占空间的内容：题目背景长篇复述、软件版本、泛泛模型原理、“模型效果较好”等空话。

### 正文前 2—4 页：问题分析 + 技术路线 + 数据/变量框架

这一段要让评委迅速判断“你有没有读懂题”。建议至少包含：

- 每问的输入—任务—输出；
- 前一问如何为后一问提供参数/边界/候选集合；
- 一张有信息的技术路线图或问题关系图；
- 数据结构、关键约束、目标指标的初步判断。

### 每问模型段：先把“主公式/主约束”露出来

不要把最关键的目标函数埋在两页模型背景介绍之后。推荐顺序：

> 本问目标 → 决策变量 → 目标函数 → 核心约束/核心统计模型 → 参数估计/求解算法 → 结果 → 检验。

### 每问末尾：必须有一个“结论块”

用 3—5 句话完成：

> 得到了什么 → 比基准好多少 → 为什么合理 → 在什么条件下稳定 → 下一问如何使用。

这样即便评委在初筛时跳读，也能抓住本问的得分点；复审时再回到公式和算法细节。

# 第二篇：2021—2025 C 题优秀论文横向学习

## 2.1 五年演化总览

| 年份 | C 题方向 | 核心数学任务 | 高分论文常见主线 | 对今年最有用的能力 |
|---|---|---|---|---|
| 2021 | 企业原材料订购与运输 | 综合评价 + 需求/供货估计 + 订购运输优化 | 评价供应商 → 缩小候选 → 订购计划 → 运输分配 → 稳健性 | “评价结果进入优化”的链条 |
| 2022 | 古代玻璃制品成分分析与鉴别 | 统计关系 + 分类/聚类 + 鉴别 | 数据清洗 → 统计差异 → 分类细分 → 鉴别规则 → 敏感性 | 统计解释、类别稳定性 |
| 2023 | 蔬菜类商品自动定价与补货 | 多表数据分析 + 预测 + 价格关系 + 利润优化 | 多表连接 → 时间聚合 → 规律 → 预测 → 定价补货优化 | 数据工程、预测—优化闭环 |
| 2024 | 农作物的种植策略 | 多期混合整数规划 + 不确定性 + 相关性 | 确定性规划 → 不确定性风险 → 相关性情景 → 方案比较 | 约束完整性、风险与鲁棒性 |
| 2025 | NIPT 时点优化与异常判定 | 纵向数据 + 生存/时点 + 分类 | 重复测量诊断 → 时点决策 → 多因素扩展 → 异常分类 | 数据结构驱动选模、检验链 |

五年共同点不是“都用了同一个模型”，而是：

> **先识别任务和数据结构，再建立最简单的合理基线；只有当基线暴露出问题时才升级；最终把统计/预测结果转成可执行决策，并用检验证明它值得相信。**

## 2.2 2021 C：评价不是终点，规划才是闭环

2021 C 优秀论文最值得学的不是 TOPSIS、聚类或某个评价公式，而是“评价—筛选—规划”的职责分工：

- 评价模型解决“谁更值得选”；
- 需求/供货能力估计解决“要多少、能供多少”；
- 订购模型解决“何时向谁订多少”；
- 运输模型解决“如何分配运输能力”；
- 稳健性分析回答“某供应商失效、损耗率改变后方案还行不行”。

**新手错误**：问题一做完供应商排名后，问题二重新开始另一个模型，排名没有进入后续优化。  
**国一风格**：把前一问的输出明确写成后一问的参数、候选集合、权重、边界或初值。

## 2.3 2022 C：统计结果必须翻译回题目语境

材料成分题的难点不在“会不会聚类”，而在于：

- 为什么某些成分需要变换或标准化；
- 哪些成分差异具有统计意义；
- 分类边界是否与玻璃类型/风化状态的背景一致；
- 新样本的鉴别规则是否稳定；
- 阈值、测量误差改变后结论会不会翻转。

因此，C 题做统计分析时不要停在“p<0.05”或“聚成 3 类”，而要继续回答：

> **这个统计差异对题目决策意味着什么？它能不能支撑分类、预测或下一步优化？**

## 2.4 2023 C：最标准的“数据—预测—优化”业务链

2023 C 的优秀论文尤其适合你们训练 C 题：

1. 多张附件先统一主键和统计口径；
2. 在品类/单品、日/周/月等多粒度做描述统计；
3. 用相关、聚类、季节性、ACF/PACF 等识别规律；
4. 建立可验证的短期销量预测；
5. 再研究价格—销量、加价率、损耗率等关系；
6. 将预测需求和价格关系作为优化模型输入；
7. 输出每天/每类/每单品的补货与定价策略；
8. 与历史策略、平均策略或基准模型比较。

2023 年的闪光点还包括“诊断后改模”：如果 ARIMA 残差或拟合表现不好，不是继续调参数把图修漂亮，而是解释为什么数据结构不满足模型，并改用更合适的模型。

## 2.5 2024 C：把 C 题的“约束优化 + 风险”推到很典型的位置

2024 C 题明确要求 2024—2030 多年种植规划，包含地块类型、季节、作物适配、不能重茬、三年内至少一次豆类、种植不能太分散、单地块面积不能太小、销售上限等多重约束。

这类题最重要的不是“用 GA 还是 LINGO”，而是先回答：

- 决策变量能否表达“年份—季节—地块—作物—面积”；
- 是否需要 0-1 变量表达“种/不种”；
- 轮作、豆类、面积下限、分散程度如何转成约束；
- 超产滞销与半价销售如何进入收益函数；
- 第 2 问的销售量、亩产量、成本、价格不确定性怎样进入情景或风险模型；
- 第 3 问的替代/互补、价格—需求—成本相关性如何进入模拟数据与相关结构。

王尚平老师讲评中特别指出：如果直接用相邻年份面积乘积等于 0 表示“不重茬”，会把模型变成非线性规划；引入是否种植的 0-1 变量可以更清楚地表达逻辑约束。这是一个非常典型的“**建模表达方式决定求解难度**”的例子。

## 2.6 2025 C：先判断“重复测量、删失、不平衡”，再决定模型

2025 C 优秀论文把“数据结构驱动模型选择”体现得最明显：

- 同一孕妇多次检测 → 记录并不独立 → 混合效应模型/LMM/NLME 更合理；
- “直到最后一次观察仍未达到阈值” → 右删失 → 生存分析/Cox/AFT；
- 女胎异常样本明显少 → 类别不平衡 → class weight、SMOTE/Borderline-SMOTE 等；
- 分类任务先有 Logistic 基线，再用 RF/XGBoost/LightGBM 等增强，并看 Recall、F1、AUC 而非只看 Accuracy。

**2025 给 C 题最重要的升级**：不要问“我会什么模型”，先问“数据到底是什么结构”。

# 第三篇：2024 C 题讲评带来的“评审优先级”修正

## 3.1 训练评分参考告诉我们：先把核心问题和结果文件做对，再谈花哨创新

王尚平老师的讲评给出一套训练用评分参考：摘要与整体印象 10 分，问题 1 为 40 分，问题 2 为 20 分，问题 3 为 15 分，三个结果表合计 15 分。该分配不是全国组委会公开的统一官方细则，但对训练非常有价值。

它传递了一个重要的比赛策略：

> **主问题的正确性、完整性、结果文件，比在最后一问堆复杂算法更重要。**

因此，比赛时间分配建议采用“保底优先级”：

1. **先保证问题 1 的决策变量、目标函数、全部硬约束与结果文件正确；**
2. 再做问题 2 的不确定性与风险；
3. 再做问题 3 的相关性和创新扩展；
4. 最后再优化图表、语言与更高级算法；
5. 任何时候都不要牺牲结果表完整性去追求一个未验证的复杂模型。

## 3.2 2024 C 的优秀解答应让“模型—算法—程序—结果”一一对应

讲评明确强调，评阅应关注：

- 建模过程是否合理；
- 模型表述是否准确；
- 模型、算法、程序、结果是否存在清楚关联；
- 求解过程和结果是否可信；
- 种植方案是否可行。

这一条可以直接推广为所有 C 题的写作检查：

> **每个结果表都能追溯到模型；每个模型都能追溯到题目要求；每个算法都能解释为什么能求这个模型。**

如果论文里出现一个模型，但最终方案并不是由它算出的；或者代码用了另一套逻辑而正文没写，评委很容易失去信任。

## 3.3 2024 C 讲评给出的一个“训练优先级”：大题、结果文件、硬约束优先

王尚平老师讲评中的训练参考把“摘要及整体印象、问题一、问题二、问题三、三个结果表”分别赋予不同权重，其中问题一和结果表占比很高。这个分值分配**不是全国组委会公开统一评分表**，但对备赛极有启发：

1. **先保证主问题完成度**：问题一通常奠定决策变量、目标函数和核心约束，后续问题是在此基础上扩展；基础模型错，后面越复杂越危险。
2. **题目要求的结果文件本身就是答案的一部分**：不能“论文写得漂亮，但 result 文件漏填、越界或格式错误”。
3. **风险与相关性属于升级层**：应在确定性可行模型跑通后再加，否则很容易陷入 MINLP/复杂随机规划而没有可靠结果。
4. **创新必须服务可解性或合理性**：讲评中特别提醒，不合理的变量乘积会把本可线性化的逻辑约束变成非线性规划，造成计算困难。好的创新有时不是更复杂，而是更聪明地表达约束。

讲评在问题三还强调：评阅时会看**建模过程的合理性、模型表述的准确性、模型—算法—程序—结果之间的关联、求解与结果的可信度、方案可行性**。这几项应作为所有 C 题的复审核验清单，而不只适用于农作物题。
