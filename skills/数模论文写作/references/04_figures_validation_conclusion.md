# 第十篇：图表规范——图表不是装饰，是评审证据

## 10.1 图题、表题与编号

- **表题放表上方**：表 1、表 2……，默认五号宋体、居中；
- **图题放图下方**：图 1、图 2……，默认五号宋体、居中；
- 图表必须在正文先被引用，再出现或紧随引用；
- 单位写在列名/坐标轴，不要让评委猜；
- 外部图/数据应标注来源并在参考文献中对应；
- 附件直接生成的图，也要说明数据范围和统计口径。

## 10.2 三线表推荐结构

| 模型 | MAE | RMSE | \(R^2\) | 选择理由 |
|---|---:|---:|---:|---|
| 基线模型 | … | … | … | 简单、可解释 |
| 改进模型 | … | … | … | 误差更低/残差更稳定 |

正式排版时采用“三线表”：顶部线、表头下方线、底部线，不画满格竖线。**表格正文默认五号宋体，英文与阿拉伯数字用 Times New Roman；信息量较大的复杂表可统一降至小五。**

## 10.3 图的选择原则

| 想回答的问题 | 推荐图 |
|---|---|
| 时间趋势、季节变化 | 折线图、季节子序列图 |
| 两变量关系 | 散点图 + 拟合线/置信带 |
| 分组差异 | 箱线图/小提琴图/误差条图 |
| 相关结构 | 相关热力图 |
| 模型误差 | 残差图、Q-Q 图、误差分布 |
| 分类表现 | ROC/PR、混淆矩阵 |
| 优化权衡 | Pareto 前沿、敏感性曲线 |
| 多年/多地块方案 | 热力图、堆叠图、甘特式矩阵 |

不建议：

- 无必要的 3D 柱状图；
- 十几个颜色的饼图；
- 只为了“好看”的渐变背景；
- 没有坐标单位、图例、数据范围的图。

## 10.4 图表分析的四句式

> **第一句：读图结论。** 图 6 显示，销量在周末整体高于工作日，并在 17—19 时出现峰值。  
> **第二句：给数字。** 周末日均销量较工作日提高约 XX%，峰值时段贡献全天销量的 XX%。  
> **第三句：解释原因/结构。** 该差异说明需求同时具有周内周期和时段集中性。  
> **第四句：进入模型。** 因此后续预测模型加入星期变量，并在补货模型中采用日粒度需求约束。

最忌讳：

> “由图可知数据波动较大，符合实际情况。”

这种句子没有任何可评阅信息。

## 10.5 同一张图，在“初审”和“复审”中的职责不同

- **初审看图**：评委想快速知道有没有规律、有没有结果、模型主线是否完整。因此图应直观、标题明确、关键趋势突出。
- **复审看图**：评委会进一步问“这张图如何证明模型合理？”因此图必须有统计口径、单位、样本范围，并在正文给出数字和模型含义。

所以高分图表最好同时满足两件事：

1. **扫一眼能读出结论**；
2. **细看能找到证据**。

推荐把“最有价值的图”优先留给：

- 技术路线/问题依赖图；
- 数据结构诊断图；
- 基线 vs 改进模型对比图；
- 优化方案对比/风险分布图；
- 灵敏度/稳健性图。

不要用大量装饰性图把真正的证据图挤到附录。

## 10.6 分类图、混淆矩阵与热力图的可读性规范

2025 C 题二分类训练暴露出一个典型问题：**如果底色过深，即使图本身“颜色强烈”，单元格数字也会难以识别。**

因此统一规定：

1. 混淆矩阵、相关热力图优先使用**低饱和、浅—中等明度**配色；
2. 每格显示数值时，文字颜色必须与背景形成充分对比；
3. 深色单元格需要自动切换为浅色文字；
4. 处理前/后、模型 A/B 对比时使用同一色阶范围；
5. 二分类图优先让 TP、TN、FP、FN 与对应数值清晰可读；
6. 不使用深色大面积背景、霓虹渐变、发光与 3D 等影响信息识别的效果。

> **图表颜色的第一职责是区分信息，第二职责才是美观。数字不可读时，配色即判定为失败。**


## 10.7 图表叙事规则：重要图表不得“裸接小标题”

重要图表的正文位置统一采用：

```text
小标题/自然段
↓
图前引入：为什么需要这张图、要回答什么、统计口径是什么
↓
图/表
↓
图后解释：读图结论 + 量化证据 + 模型含义/下一步用途
```

### 图前至少回答三个问题

1. **为什么画？**
2. **要验证/比较什么？**
3. **数据范围、样本、变量或指标口径是什么？**

### 图后至少回答三个问题

1. **最主要的规律是什么？**
2. **用哪个数字/趋势证明？**
3. **这个规律怎样改变下一步模型？**

**例外**：题目强制结果表、纯方案汇总表可以直接由一句正文引用引出，不强制写完整自然段。

### 成组图优先组合

若多张图：

- 对象相同；
- 横纵轴口径相近；
- 承担同一分析目的；

则优先做成 `(a)(b)` 或 `(a)(b)(c)` 组合图。例如：

> `(a) Y 浓度—孕周` + `(b) Y 浓度—BMI`

比连续放两张孤立散点图更利于比较，也更节省页面。

## 10.8 图表视觉完成度：禁止默认程序图直接进入论文

统计结果图可以由代码生成，但不得把 Matplotlib、Excel 等默认样式未经设计直接放入正式论文。进入正文前至少检查：

1. 图型与图名语义一致；“分布”“置信区间”等标题必须由相应图型真实表达；
2. 全文字体、字号、线宽、坐标轴、网格强度、图例、标注和色彩语义统一；
3. 配色低饱和、可打印、少色，同一语义在全文保持同色；
4. 绘图区占比和信息密度合理，无大面积无效留白；
5. 同类比较采用统一坐标范围、量纲和色阶，避免视觉尺度误导；
6. 代码图经过人工逐图验收，正式流程图仍优先用 PPT/可编辑矢量方式人工重绘。

合格标准是评委扫一眼能读结论，细看能核对证据，且整篇图像具有统一的人工设计语言。

# 第十一篇：不同模型的检验标准——数据分析一定要验证，但不要用一套“灵敏度分析”糊所有题

> **统一规范**：数据分析类问题必须有可靠性验证；若模型含连续关键参数、阈值、权重、风险系数或边界参数，优先增加参数—结果敏感性曲线。


## 11.1 回归/统计模型

若关系形式并非题面直接指定，**先完成简单基线与合理候选模型的统一比较，再报告最终模型参数。**

至少考虑：

- 候选模型 AIC/BIC、验证误差或其他统一选择指标；
- 系数显著性与置信区间；
- \(R^2\)/调整 \(R^2\)；
- 残差独立性、异方差、正态性（按模型需要）；
- 多重共线性；
- 训练/验证误差；
- 效应方向是否符合背景。

标准话术：

> 改进模型的验证集 RMSE 由【A】降至【B】，同时残差与拟合值之间未呈现明显结构性趋势，说明误差下降并非单纯由训练集拟合增强造成。

## 11.2 时间序列预测

- 滚动/扩展窗口验证；
- MAE、RMSE、MAPE、WAPE（MAPE 注意零值问题）；
- 与季节均值/ARIMA 等基线对比；
- 残差白噪声/ACF；
- 多步预测误差随步长变化。

## 11.3 分类模型

- 分层交叉验证；
- 混淆矩阵；
- Precision、Recall、F1；
- ROC-AUC；类别严重不平衡时优先 PR-AUC；
- 筛查/高风险判定任务必要时同时报告 Sensitivity、Specificity、PPV、NPV；
- 阈值敏感性；
- 若做 SMOTE，只能在训练折内部做，防止数据泄漏。

## 11.4 综合评价

- 权重变化 ±5%/±10% 后排名是否稳定；
- 等权、熵权、AHP 等结果对比；
- 删除一个指标后的排名变化；
- 指标相关性，避免高度重复计权。

## 11.5 优化模型

至少回答：

1. 最优解是否满足全部约束；
2. 与基准/人工方案相比提升多少；
3. 关键参数改变时最优方案是否剧烈变化；
4. 启发式算法重复运行结果是否稳定；
5. 可行解、最优解/下界/上界之间关系，以及 optimality gap（若求解器能给）。

> **优化题最有说服力的检验通常不是“适应度曲线下降了”，而是“方案可行 + 相较基准更好 + 参数扰动不翻车”。**

## 11.6 随机模拟/不确定性模型

报告：

- 随机变量分布或区间依据；
- 模拟次数；
- 随机种子/重复次数；
- 收益/风险的均值、标准差、分位数/置信区间；
- 样本数增加时结果是否收敛。

若题目只给“介于 5%—10%”但没有说服从什么分布，写“均匀分布”时必须明确：

> “这是建模假设，不是题设事实；并通过不同分布/边界情景检验结论稳健性。”

# 第十二篇：结论风格——量化、对比、边界、价值

## 12.1 每问结论建议采用“结果—对比—解释—边界”四句式

> 在【条件】下，模型得到【核心方案/预测/分类结果】，关键指标为【数值】。与【基准方案】相比，【收益/误差/风险】改善【数值或百分比】。这一变化主要来自【机制/约束/关键变量】。当【参数】超过【范围】时方案发生明显变化，因此该结论适用于【边界条件】。

这比“模型效果良好，有实际意义”有信息得多。

## 12.2 模型优点不要写成自夸

**推荐**：

> （1）模型将【上一问结果】直接作为【下一问参数/约束】，使分析与决策形成闭环；  
> （2）通过【0-1 变量/随机效应/风险项】显式刻画了【现实约束】，提高了解的可解释性；  
> （3）使用【滚动验证/情景模拟】检验模型，在【扰动范围】内核心结论保持稳定。

**不推荐**：

> 模型精度很高、创新性很强、适用范围很广。

## 12.3 模型缺点要“具体、可改、不过度自毁”

> 模型将【某关系】近似为【形式】，在当前数据区间内能够取得稳定结果，但当【外部环境】发生明显结构变化时，参数可能失效。后续可通过【滚动估计/外部数据/鲁棒模型】进行更新。

## 12.4 改进方向必须一一对应局限

| 局限 | 改进 |
|---|---|
| 样本少 | Bootstrap/贝叶斯/收集更多跨期数据 |
| 参数随时间变 | 滚动窗口、状态空间/时变参数 |
| 区间不确定 | 情景/鲁棒优化 |
| 相关结构未知 | Copula/相关矩阵/外部数据校准 |
| 类别不平衡 | 阈值优化、class weight、重采样 |
| 静态策略 | 滚动优化/在线更新 |
