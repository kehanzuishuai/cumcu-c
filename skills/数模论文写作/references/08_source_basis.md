# 参考资料（手册依据）

1. 全国大学生数学建模竞赛组织委员会：《全国大学生数学建模竞赛章程（2023 年修订稿）》；其中明确评奖主要关注假设合理性、建模创造性、结果正确性与文字表述清晰程度。
2. 全国大学生数学建模竞赛组织委员会：《全国大学生数学建模竞赛全国奖项评阅工作规范（2023 年修订稿）》及《赛区评阅工作规范（2025 年修订稿）》；前者明确全国一等奖申报论文至少由 3 位评委独立评阅、分歧较大时复议，后者明确赛区评阅前应统一评阅细则并可先试评。
3. 全国大学生数学建模竞赛组织委员会：《全国大学生数学建模竞赛论文格式规范（2026 年修订稿）》；用于确定纸质/电子论文结构、摘要与正文页数、附录、源程序、支撑材料、匿名、引用、文件格式与 20MB 大小限制。
4. 王尚平：《C 题 农作物的种植策略——数学建模问题解答与评析》，2025.7；用于提炼 2024 C 的决策变量、约束线性化、不确定性风险和相关性建模训练重点。
5. 用户提供的微信评审文章截图：《数学建模竞赛论文评阅的一般过程》《数学建模竞赛评阅流程》；用于提炼初审—预选—复审—终审—最终确认的“实战阅读视角”，其中单篇时长仅视为经验性示意。
6. 2024 年高教社杯全国大学生数学建模竞赛 C 题《农作物的种植策略》原题。
7. 用户提供的 2021—2025 年 C 题优秀论文与 2025 年优秀论文展示样本。
8. 用户提供的《2024 年高教社杯数学建模国赛 ABCDE 赛题评分细则》：该文件正文自述为 AI 生成的非官方参考材料，本手册仅将其作为训练提示，不视为官方标准。
9. 2025 C 题训练后教师复盘要点：六段式摘要、问题重述两层结构、三级标题密度、数字/英文 Times New Roman、二分类图浅色可读性；本手册将其与 2021—2025 优秀论文共性结合后作为队内新增规范。
10. 全国大学生数学建模竞赛组织委员会：《全国大学生数学建模竞赛人工智能工具使用规定（2026 年试行）》；用于确定 AI 使用公开透明、核心建模由参赛队主导、人工审查核实、论文声明位置以及 `AI 工具使用详情.pdf` 等要求。
11. 用户提供的《摘要 AI 痕迹高亮标注报告》；用于归纳套话升华、模板结构、空洞虚化、推销夸大四类“建议复查”语言特征。该报告明确说明高亮仅用于风格复查，不作为 AI 生成判定；本手册据此制定去机械化写作审校规范。
12. 当前安装的“数模审题” Skill：用于定义写作入口的 `PAPER_READY` 门禁、final 文件白名单、五份冻结合同、`object + semantic_role + dimensions` 粒度接口，以及禁止读取 draft/backup/archive 的下游边界；本 Skill 不复制其审题逻辑。
13. 2021 C085、2022 C155、2023 C050/C126/C235 等优秀 C 题论文版式抽查：用于验证“一级标题居中、二三级标题左对齐、正文紧凑首行缩进、表题上置、图题下置、三线表”等视觉层级；具体四号/小四/五号为本队结合教师要求后标准化的可执行字号，不声称所有历史论文使用完全相同 pt 数值。
14. 指导教师最新摘要训练要求与 2024 C 题训练对照：摘要专用页必须实际占版约 3/4 页以上且不超过 1 页；首段应先完成自然引入，再进入逐问模型与结果；本手册据此将“3/4—1 页”由建议升级为 S1 硬性版面规范，并要求通过最终编译反复校验。
15. 往年 C 题优秀论文阶段过渡专项复查：重点提炼“前问结果承接—当前不足—新增现实矛盾/约束—模型升级—本问任务”的自然转换，以及“相同点—不同点—模型变化”“先现实机制、后数学模型”“开放问从前文信息缺口出发”等写作习惯；本手册将其作为建模语言与阶段衔接规范，不机械复刻原论文句式。
16. 2021—2025 C 题优秀论文分问标题结构复查：优秀论文普遍保持“建模依据—建立/求解—结果—验证”的功能闭环，但三级标题会随统计、预测、优化、分类、风险等任务自然变化；因此本手册取消“每问固定四个同名三级标题”，改为“3—4 个功能型动态标题”。
17. 2023/2025 队内训练稿与往年优秀 C 题论文反向验收：重点发现元话语、“A—B—C”概念链、引号包装等模板化语言应在生成阶段实时控制；而标题/图表/公式编号、分页、大面积空白、图例/colorbar 碰撞、跨页表和逐页视觉验收更适合在全文冻结后的 Final QA 一次性完成，以减少重复审计与 token 消耗。
18. 2025 队内训练稿 Q1 与往年优秀 C 题关系建模写法复盘：探索性散点图应承担“识别关系形态”职责，不能直接替代模型选择；当存在多种合理函数形式时，应比较简单基线与有依据的候选模型，并通过统一指标和残差/假设诊断确定最终模型。同时，重要图表不得裸接小标题，须形成“图前用途与统计口径—图中证据—图后量化解释与模型用途”的完整叙事。
19. 唯一共享规范 `../../_shared/cumcm/C题规范.md`（源修订 2026-08-31，安装标准版本 2026.09.01）：用于同步摘要首段、粗体锚点、问题重述压缩、标题终审、符号分类、数据概览图、培训计划更新、附录分页和图表视觉完成度规则；旧日期副本不再作为规范入口。
