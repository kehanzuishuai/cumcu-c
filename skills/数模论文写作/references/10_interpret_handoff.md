# 数模审题到论文写作交接接口

本文件只定义审题 final 到写作的读取边界，不复制或修改上游审题逻辑，也不新增合同。

## 1. 启动门禁

正式建模写作必须取得上游 final validator 生成的 `paper_ready_manifest.json`。清单状态必须为 `PAPER_READY`，且规范 hash、两个 final 与五份冻结合同的路径和 SHA-256 必须全部匹配。文件名、`BLOCKING=0`、人工口头说明或合同数量都不能替代该状态。

若清单缺失、状态不是 `PAPER_READY`，或任一必需 final/合同缺失、hash 失配，停止本 Skill并输出：

```text
BLOCKER: UPSTREAM_NOT_PAPER_READY
证据: 缺失或未通过的状态/文件
影响: 禁止启动正式建模写作
建议处理: 返回“数模审题”完成 final 校验与冻结
是否返回赛题解读阶段: yes
```

## 2. 允许读取的上游文件

| 类别 | 固定文件 |
|---|---|
| 上游证明 | `paper_ready_manifest.json` |
| 最终自然语言解读 | `赛题解读_final.md` |
| 最终分问模型方案 | `Q1-QN模型方案_final.md`，`N` 为实际小问数 |
| 歧义决定 | `歧义与口径确认.md` |
| 粒度合同 | `建模粒度合同.md` |
| HARD 约束 | `约束冻结表.md` |
| 关键题意决定 | `题意决定冻结合同.md` |
| 普通模型假设 | `模型假设台账.md` |

只从正式交接目录读取上述文件。禁止读取任何 backup/archive 目录（包括 `_archive/`）、`*_draft.md`、无 `_final` 后缀的旧模型方案或历史副本；不得在 final 缺失时拿历史文件顶替。

原始/清洗数据、结果模板、已有代码与结果、当届官方格式和 AI 规则属于门禁通过后的工作材料，不属于审题交接文件；它们不能覆盖冻结事实。

## 3. 写作阶段不可重解释的事实

- `赛题解读_final.md` 中的最终题意口径；
- `约束冻结表.md` 中全部 HARD 约束；
- `建模粒度合同.md` 中每个稳定 ID 的 `object + semantic_role + dimensions` 及 `mutable` 边界；
- `歧义与口径确认.md` 和 `题意决定冻结合同.md` 中标记为 `VERIFIED`、`RESOLVED_BY_EVIDENCE` 或 `APPROVED_BY_USER` 的唯一决定，以及其 `freeze_targets`；
- 已冻结的跨问接口、候选集合、评价口径、聚合口径和输出定义。

正文、公式、代码、结果表和跨问接口必须引用同一稳定 ID/唯一口径。不得把观测粒度、决策粒度和约束粒度因维度相近而混为一类，也不得重新列出已淘汰的 A/B 方案。

`模型假设台账.md` 中的普通模型假设只能依据上游已经冻结的敏感性、诊断、稳健性或失效条件进行表述。任何新证据若要求改变模型设计、候选比较、参数、代码、结果或验证，均停止写作并返回“数模审题”重新求解、验证和冻结；若还触及题意、HARD、冻结粒度或人工确认决定，则同时重新完成相应上游确认。

## 4. 写作落点

建立每问执行表时，抄录所用合同稳定 ID，并核对正文变量、符号、单位、时间口径、代码实现和结果文件与合同一致。合同内容不必整表复制进论文，但任何省略都不能改变其约束力。
