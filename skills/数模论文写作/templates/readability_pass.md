# 关键边界可读性快速检查（仅必要时）

默认静默执行，不作为每小节必填表，也不单独输出文件。每个大问题完成后集中检查一次；只有发现明显且尚未解决的 `REVISE` 时才记录。

## 适用位置

- 大问题开头
- 跨问接口
- 模型升级
- 预测转决策
- 结果转验证
- 其他存在逻辑跳跃的小节边界

## 本检查不改变
- 公式
- 数字
- 符号定义
- 模型
- 参数
- 引用
- 实质结论

若候选比较、敏感性分析或模型诊断提供了调整模型、阈值或结论的证据，返回建模流程处理并同步更新结果链；不要在语言整理中暗中修改。

## 只检查
- [ ] 一句话只有一个主要逻辑动作
- [ ] 没有“由于A、同时B、考虑C、因此D、从而E”的超长链
- [ ] 每段围绕一个主要结论
- [ ] 上一段结论能解释下一段为什么出现
- [ ] 模型名出现前已有数据/结构/诊断依据
- [ ] 无重复“这说明—进一步表明—由此可见”
- [ ] 普通步骤没有被包装成框架/体系
- [ ] 段尾没有机械升华
- [ ] 具体对象多于抽象名词

## 最终判断

- 清楚：PASS / REVISE / NOT_APPLICABLE
- 过渡：PASS / REVISE / NOT_APPLICABLE
- 闭环：PASS / REVISE / NOT_APPLICABLE
- 问题位置：
- 定点修改：
- 复查结果：PASS / REVISE / NOT_APPLICABLE

存在明显 `REVISE` 时，只修改相关句段并复查；不要因轻微措辞偏好反复打断写作。
