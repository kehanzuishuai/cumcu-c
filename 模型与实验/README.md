# 模型与实验

本目录汇总四问的**模型选择、求解代码、消融与对照实验**材料，作为 `基于风险修正与滚动时域优化的微网购电与储能调度.pdf` 的可复现支撑。

```text
模型与实验/
├─ 模型与结果/          四问模型方案与结果说明（Markdown，10 篇）
├─ 求解代码/            四问正式求解程序（Python，6 支）
└─ 消融与对照实验/      消融、敏感性、核验实验的脚本与输出
```

## 一、模型与结果（`模型与结果/`）

| 文件 | 内容 |
|---|---|
| `Q1模型与结果.md` | 问题一模型选择、变量与约束、最优调度与结果 |
| `Q2模型与结果.md` | 问题二风险修正（分位数）模型与结果 |
| `Q3模型与结果.md` | 问题三滚动时域 / 信息更新模型与结果 |
| `Q4模型与结果.md` | 问题四负载反馈与日内电价再修正模型与结果 |
| `Q1-Q4模型方案_final.md` | 四问最终模型方案对照总表 |
| `冻结工作口径.md` | 口径冻结：单位、时段、费用名称、术语 |

## 二、求解代码（`求解代码/`）

| 文件 | 作用 |
|---|---|
| `common_data.py` | 附件数据读取、时段与价格口径、公共参数 |
| `dispatch_core.py` | 调度核心：储能模型、费用分解、滚动求解骨架 |
| `q1_solve.py` | 问题一：词典序线性规划（LP）调度 |
| `q2_solve.py` | 问题二：风险修正（分位数）模型求解 |
| `q3_solve.py` | 问题三：滚动时域与信息更新求解 |
| `q4_solve.py` | 问题四：负载反馈与日内电价再修正求解 |

运行需 Python 3 与 `numpy` / `pandas` / `scipy`（LP 采用 SciPy `linprog` 的 HiGHS 求解器）。

## 三、消融与对照实验（`消融与对照实验/`）

每个实验目录统一含有 `results/`、`validation/`（独立复算）与必要的 `intermediate/` 中间产物。

| 目录 | 实验类型 | 核心结论 |
|---|---|---|
| `paper_supplemental_20260912/q3_update_combinations_alpha05/` | 消融 — 信息价值 | 八种更新时间组合；全更新相对不更新节省 60.59 万元，紧急购电减少 9.66 万 kWh |
| `paper_supplemental_20260912/q3_information_modules_alpha05/` | 消融 — 信息融合 | 三类信息 2³ 模块消融；全关 1420.58 万元 → 全开 1359.9979 万元；含 Shapley 分解与二阶交互 |
| `paper_supplemental_20260912/q2_risk_quantile_sensitivity/` | 敏感性 | τ=0 / 0.6 / 0.7 / 0.8 / 0.9 / 0.95 风险水平对照，τ=0.80 为正式锚点 |
| `paper_supplemental_20260912/q1_single_vs_lexicographic_lp/` | 消融 — 最优性解释 | 单目标 LP 与词典序 LP 费用差 3.5×10⁻⁷ 元，吞吐量差 −0.00000792 kWh；二级目标为等价最优解的择优规则 |
| `paper_supplemental_20260912/future_information_perturbation_audit/` | 核验 — 无前视 | 100 项测试中扰动未来真实值后计划向量不变，证明决策不依赖未来信息 |
| `q1_lp_milp_crosscheck/` | 交叉核验 | LP 与 MILP 独立建模结果互校 |
| `q3_alpha_calibration/` | 参数标定 | 负载反馈系数 α 的标定过程与独立复核 |
| `q3_alpha_five_point_sensitivity/` | 敏感性 | α=0 / 0.25 / 0.5 / 0.75 / 1.00 五点对照；α=0.50 时总费用最低 |
| `q3_q4_refinement/` | 消融 — 精修 | 负载反馈与日内电价再修正的 2×2 组合、信息模块逐步加入、期末储电量预留等对照 |

### 关于逐时段明细文件

正式结果目录中的 `*_detail.csv`（逐时段逐版本的完整明细，单文件 17—18 MB）**未纳入本仓库**：它们可由 `求解代码/` 与 `消融与对照实验/` 中的脚本原样重新生成。目录内已保留汇总表、逐日结果、独立验证 JSON 与全部脚本，足以复核每一条结论。

## 四、数值与论文的一致性

- 本目录中的汇总结论与论文正文数值一致；论文正文的**冻结锚点**为：问题一 59482.6990 kWh / 35126.9486 元；问题二 1399.7990 万元；问题三 1359.9979 万元；问题四 1468.7087 / 1429.1323 万元。
- 消融与对照实验均为**论文分析用隔离输出**，不构成对正式主模型结果的修改；正式结果以冻结口径为准。
- 各实验的 `validation/` 目录为独立复算（不同脚本、不同路径），用于交叉验证而非重复同一计算。
