# C题赛题解读（Final）

状态：PAPER_READY。

## 1. 题目定位

微网在10分钟尺度上协调外网购电、光伏利用和储能充放电。四问依次从已知供需下的日内调度，扩展到预测误差、日内信息更新和波动电价；各问均以可回算的10分钟账本输出计划、储能状态、紧急购电与费用。

## 2. 题面明确条件、冻结口径与普通模型假设

- **[题面事实]**：储能容量范围为1200—10800 kWh，最大充、放电功率均为5000 kW；Q1要求日初、日末储电量均为6000 kWh；紧急购电按对应时段电价的5倍计费。
- **[附件事实]**：附件1—4分别提供历史或实际负荷、光伏、预报和价格信息；附件5规定各问结果工作簿及汇总字段。
- **[必要推论]**：题目给出的功率单位为kW，而每个调度时段为10分钟，故各时段能量按功率乘以1/6小时统一换算；该换算不改变原始附件的时间标签。
- **[冻结建模口径]**：Q2—Q4所有计划遵守信息到达时点，未来实际负荷、光伏和价格只用于执行回放或结算；Q3/Q4-3的最终有效购电量相对0:00原计划一次结算；Q4-3在日内更新时不修正0:00形成的价格预测。
- **[模型假设]**：右端点功率按相应10分钟平均功率换算，预报插值、残差分位修正、滚动终端处理和负载反馈等设置均列入《模型假设台账》，并保留相应核验或敏感性证据。

## 3. A01已披露模板标签风险

原题自然日边界与附件5结果模板的时段标签不完全一致。本文保留官方原始标签，内部以自然日144个连续10分钟时段进行计算，并按冻结映射回填模板。该风险不改变供需平衡、SOC递推、费用或提交数据；已由10分钟底账、工作簿、独立复算和外部交叉核验覆盖。

## 4. 任务链

附件与模板审计 → 10分钟统一账本 → 确定性购电与储能调度 → 因果预测下的日计划 → 日内信息更新下的滚动调整 → 波动价格下的重新优化 → 约束复算、工作簿交付与论文结果。

## 当前正式主模型与约束总览

四问均以供需平衡、储能效率、容量范围、充放电功率上限、充放互斥和SOC递推为共同约束；各正式模型只在题目允许的信息时点决定尚未执行的购电与储能动作。各问当前正式主模型、输入输出和交付文件如下，历史候选不列入本节。

### Q1

- **动作与对象**：在一个自然日144个10分钟时段内安排购电和储能。
- **输入与输出**：输入为当天负荷、光伏和分时电价；输出为购电计划、储能充放电、SOC、弃光量和result1.xlsx。
- **决策与状态**：购电、充电、放电为决策量，SOC为状态量。
- **硬约束与目标**：满足供需、效率、容量、功率、日循环和充放互斥；先最小化购电费用，再在费用相同条件下减少储能充放电。
- **正式主模型与验证**：购电—储能词典序线性规划；以10分钟独立复算、SOC/功率/平衡核验和无储能对照验证。
- **交付**：官方模板结果文件result1.xlsx及10分钟明细账本。

### Q2

- **动作与对象**：按日提前确定正常购电，并在实际运行中处理预测偏差。
- **输入与输出**：输入为历史同星期负荷、近期光伏与实际执行账本；输出为全年计划购电、紧急购电、SOC、费用及result2.xlsx。
- **决策与状态**：日计划购电为决策量，实际SOC为跨日状态量。
- **硬约束与目标**：正常购电锁定，储能因果反馈，余缺口才紧急购电；最小化正常购电与紧急购电现金费用。
- **正式主模型与验证**：因果预测驱动的风险修正滚动线性规划；通过独立费用复算、信息截止审计和工作簿核验。
- **交付**：官方模板结果文件result2.xlsx及全年10分钟执行账本。

### Q3

- **动作与对象**：在0:00、6:00、12:00和18:00对尚未执行的当日计划作因果调整。
- **输入与输出**：输入为0:00计划、各次可得光伏预报、实际SOC和已发生负荷；输出为版本日志、最终有效购电、紧急购电、SOC、费用及result3.xlsx。
- **决策与状态**：各时点之后未执行槽的购电为决策量，SOC与已执行动作是锁定状态。
- **硬约束与目标**：保持已执行槽不可改写，按冻结调整结算口径计费，并遵守储能物理约束和信息截止。
- **正式主模型与验证**：日内预报与因果负载反馈驱动的滚动购电调整模型；通过独立回放、功率/SOC/平衡核验和工作簿核验。
- **交付**：官方模板结果文件result3.xlsx、版本日志及10分钟执行账本。

### Q4

- **动作与对象**：在波动电价下重新安排购电和储能，并分别输出每日计划与日内调整两类结果。
- **输入与输出**：输入为历史价格、实际结算价格以及对应的Q2/Q3信息权限；输出为result4-2.xlsx、result4-3.xlsx和10分钟费用账本。
- **决策与状态**：预测价格下的购电与储能为决策量，实际SOC跨日连续。
- **硬约束与目标**：计划时不可使用未来实际价格，最终按实际交付时段价格结算；分别继承Q2和Q3的正常购电、调整与紧急购电规则。
- **正式主模型与验证**：波动电价下的因果滚动购电优化模型，其中日内调整分支继承alpha=0.5负载反馈且不进行日内价格修正；通过价格预测回放、独立费用复算、信息截止和工作簿核验。
